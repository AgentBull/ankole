## Version 0.47.0 (2026-07-28)

- Wait out an upstream outage instead of failing a Background Agent Job inside it. A retryable worker Turn failure on a Job session now waits on a fixed ladder from one minute to two hours between execution attempts, so the five-attempt budget spans roughly 3.7 hours; the previous 5–120-second exponential backoff let a production Job burn all attempts inside one 47-minute provider outage and fail. Ordinary actor events keep the short backoff because a user waits on them. Cover the ladder in the Job dispatch exhaustion test and record the wait contract in the Background Agent Job design document.

- Forward `prompt_cache_key` on OpenRouter chat requests. OpenAI requires the key for reliable prompt-cache routing on GPT-5.6 models, and every Codex request shares one identical prompt prefix, so concurrent Jobs contended for one cache route while the chat path silently dropped the key that both runtimes already send. The direct OpenAI Responses path preserved it; the OpenRouter provider now copies the public request value into its provider options. Other OpenAI-compatible providers stay unchanged because their upstreams may reject the field. Cover the forwarded key and the keyless request in the Responses dispatch tests.

- Remove the obsolete system-prompt epoch marker, its literal-string assertions, and its documentation. Agent Computer already renders the current PostgreSQL-backed prompt on every turn, and prompt-cache routing already hashes the real instruction and tool prefix, so the manual marker had no remaining runtime owner or cache function.

- Give Brain Stage A an output budget that survives its own reasoning, and rewrite its prompt for current models. The episode summary call now reserves 8,192 output tokens at medium reasoning effort, because reasoning consumed the whole previous 1,024-token cap on a large part of the calls and returned no episode text at all. - Decode AIGateway opaque tool values by their own versioned prefix instead of by the request's tool plan. A Codex local compaction request replays the full history without tool definitions, so the plan-gated lowering skipped replayed collaboration payloads and the summarizer model received Base64 blobs in place of every inter-agent instruction.
