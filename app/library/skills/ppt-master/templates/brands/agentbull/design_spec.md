# AgentBull Brand Specification

> Identity-only preset. No SVG page roster; pages are composed freely under these constraints.

## I. Brand Overview

| Property | Value |
|---|---|
| Brand Name | AgentBull |
| Use Cases | Agent OS product decks, workflow automation explainers, release updates, customer-facing technical briefings |
| Tone | Sharp, energetic, pragmatic, product-led, operator-friendly |

## II. Color Scheme

| Role | HEX | Provenance | Notes |
|---|---|---|---|
| primary | `#ff4669` | fact | AgentBull pink; use for main emphasis, section markers, hero accents |
| primary-dark | `#b91f3f` | derived | Deep emphasis on light backgrounds |
| accent | `#16a3a6` | derived | Cool contrast for secondary callouts and diagrams |
| text | `#18181b` | derived | Main text on light surfaces |
| muted-text | `#71717a` | derived | Secondary text and chart labels |
| bg | `#ffffff` | derived | Default presentation background |
| surface | `#f7f7f8` | derived | Subtle panels and table bands |
| border | `#e4e4e7` | derived | Fine separators and low-emphasis borders |

Keep `#ff4669` visually dominant but not full-slide dominant. Use the cool accent to distinguish structure, process, or verification states from brand emphasis.

## III. Typography

| Role | Family | Weight |
|---|---|---|
| title | `Inter, Arial, "Microsoft YaHei", sans-serif` | 650-750 |
| body | `Arial, "Microsoft YaHei", sans-serif` | 400 |
| mono | `Consolas, "Courier New", monospace` | 400 |

`Inter` may be unavailable on recipient machines. If the deck must travel without embedded fonts, lock `Arial, "Microsoft YaHei", sans-serif` for both title and body.

## IV. Logo

No logo asset is bundled with this preset. Use a text wordmark until an approved AgentBull logo file is added.

| Form | Usage |
|---|---|
| `AgentBull` text wordmark | Cover, title footer, final slide, and compact header identity |

- Wordmark color: `#18181b` on light backgrounds; `#ffffff` on dark or primary-color backgrounds.
- Accent underline or dot may use `#ff4669`.
- Do not invent a symbol, mascot, or logo graphic.

## V. Voice & Tone

- Formality: direct-professional
- Person: we / you (English), 我们 / 你 (Chinese)
- Emoji: avoid
- Abbreviations: common-abbrev-allowed
- Style: state the operational value first, then the implementation fact that proves it

## VI. Icon Style

- Preference: simple filled or rounded-stroke icons

When using bundled icon libraries, prefer either `tabler-filled` or a restrained `tabler-outline` set for the whole deck. Keep icons functional; avoid decorative icon grids.
