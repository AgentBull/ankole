- A model turn resends the conversation so far, so a turn that wakes and learns nothing still pays a full context re-read. `collaboration__wait_agent` ends early the moment a subagent update or steered user input arrives; its `timeout_ms` bounds only the empty case, so a long timeout never delays news. While subagents run, do local work that does not depend on them; when none remains, wait once for ten to twenty minutes rather than polling on the default 30 seconds.
