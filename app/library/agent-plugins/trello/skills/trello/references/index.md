# trello operations

Choose the operation below, then read only its linked contract.

- [add_boards](add_boards.json): Creates a new Trello board; the 'name' parameter is required for creation, and various preferences can be customized or cloned from a source board.
- [add_card_vote](add_card_vote.json): Casts a 'yes' vote for a specified member on a Trello card; a member can only vote once per card.
- [add_cards](add_cards.json): Creates a new card in a Trello list. Only `idList` is required; `idBoard` is optional as the API determines the board from the list.
- [add_cards_actions_comments_by_id_card](add_cards_actions_comments_by_id_card.json): Adds a new text comment, which can include @mentions, to a Trello card specified by its ID; file attachments are not supported via this action.
- [add_cards_attachments_by_id_card](add_cards_attachments_by_id_card.json): Adds an attachment to a Trello card by `idCard`; specify either a `file` to upload or a `url` to link, but not both.
- [add_cards_checklists_by_id_card](add_cards_checklists_by_id_card.json): Adds a checklist to a Trello card: use `value` to add a specific existing checklist, `idChecklistSource` to create a new checklist by copying an existing one (optionally using `name` for the new checklist's name), or `name` to create a new empty checklist from scratch.
- [add_cards_id_labels_by_id_card](add_cards_id_labels_by_id_card.json): Adds an existing label to a Trello card; `idCard` identifies the card and `value` is the ID of the label to add. Both card and label must already exist.
- [add_checklists](add_checklists.json): Creates a new checklist on a Trello card, either by name or by copying from `idChecklistSource`, targeting an `idCard` or `idBoard`; this action creates only the checklist structure, not its items.
- [add_checklists_check_items_by_id_checklist](add_checklists_check_items_by_id_checklist.json): Adds a new check item to a specified Trello checklist; this action does not update existing check items.
- [add_labels](add_labels.json): Creates a new label with a specified name (required) and color on a Trello board (idBoard required); this action defines the label but does not apply it to cards.
- [add_lists](add_lists.json): Creates a new list on a specified Trello board, with options to copy an existing list, set its position, initial state (archived/subscribed), and does not modify existing lists or move cards.
- [add_member_to_card](add_member_to_card.json): Assigns a Trello member to a specific Trello card by card ID (or short link) and member ID.
- [archive_all_list_cards](archive_all_list_cards.json): Archives all cards in a Trello list; while cards can be restored via the Trello interface, this action does not provide an unarchive function.
- [convert_checklist_item_to_card](convert_checklist_item_to_card.json): Converts a checklist item into a new card (useful for promoting a subtask), which inherits some properties from the item; this is irreversible via the API and offers no customization during conversion.
- [create_action_reaction](create_action_reaction.json): Tool to add a new emoji reaction to a Trello action. Use when acknowledging comments or actions with reactions.
- [create_board_label](create_board_label.json): Creates a new label on an existing Trello board.
- [create_card_label](create_card_label.json): Adds a label to an existing Trello card (specified by `idCard`), defining the label by `name` and either `color` or the overriding `value` (which specifies color by name); a new label is created on the board if a matching one (by name/color combination) doesn't already exist.
- [create_member_board_star](create_member_board_star.json): Stars a Trello board for a member at a specified position; the board must exist and be accessible to the member.
- [create_organization](create_organization.json): Creates a new Trello organization (Workspace) with a `displayName` (required), and optionally a description, website, and various preferences (e.g., board visibility, member invitation restrictions).
- [delete_action](delete_action.json): Deletes a specific Trello action, such as a `commentCard`, by its ID; this is an irreversible operation and only applies to deletable action types, as many (especially system-generated) actions cannot be deleted.
- [delete_action_reaction](delete_action_reaction.json): Permanently deletes a specified reaction from a Trello action. Use when you need to remove a reaction that was previously added to an action.
- [delete_board](delete_board.json): Permanently deletes a Trello board by its ID. This is an irreversible action that removes the board and all its contents.
- [delete_card_attachment](delete_card_attachment.json): Permanently removes a specified attachment from a Trello card; this action is irreversible and requires that both the card and the attachment exist.
- [delete_card_check_item](delete_card_check_item.json): Permanently delete one checklist item from a Trello card.
- [delete_card_checklist](delete_card_checklist.json): Permanently deletes a specific checklist from a Trello card.
- [delete_card_comment](delete_card_comment.json): Deletes a specific comment action (identified by `idAction`) from a Trello card (identified by `idCard`); this operation is irreversible and only affects comments.
- [delete_cards_by_id_card](delete_cards_by_id_card.json): Permanently deletes an archived Trello card specified by its `idCard`.
- [delete_cards_members_voted_by_id_card_by_id_member](delete_cards_members_voted_by_id_card_by_id_member.json): Removes a member's vote from a Trello card. The operation requires the member to have already voted on the card; attempting to delete a non-existent vote returns a 400 error. Voting must be enabled on the board.
- [delete_checklist_item](delete_checklist_item.json): Permanently deletes a specific check item from a checklist on a Trello card; this operation is irreversible and only affects the specified item, not the entire checklist.
- [delete_checklists_by_id_checklist](delete_checklists_by_id_checklist.json): Permanently and irreversibly deletes a Trello checklist and all its items using the `idChecklist`.
- [delete_labels_by_id_label](delete_labels_by_id_label.json): Permanently deletes an existing label from a Trello board by its ID; this operation is irreversible via the API.
- [delete_organizations_by_id_org](delete_organizations_by_id_org.json): Permanently deletes a Trello organization and all its associated data; this action is irreversible and requires caution.
- [delete_organizations_logo_by_id_org](delete_organizations_logo_by_id_org.json): Deletes an existing Trello organization's custom logo, restoring its default and leaving other settings unchanged; if no custom logo exists, it succeeds without effect.
- [delete_organizations_members_by_id_org_by_id_member](delete_organizations_members_by_id_org_by_id_member.json): Permanently removes a member from a Trello organization by ID, revoking all access to its content; re-invitation is required for renewed access, and this does not delete the member's Trello account.
- [dismiss_member_message](dismiss_member_message.json): Dismisses a one-time message for a Trello member, adding it to their dismissed messages list. This endpoint marks a specific one-time message (notification, banner, or prompt) as dismissed for the specified member. Once dismissed, the message will not be shown to the user again. Common use cases include dismissing onboarding messages, feature announcements, or team-specific prompts. Requires write access to the member's account. Use 'me' as idMember for the authenticated user.
- [get_actions_board_by_id_action](get_actions_board_by_id_action.json): Retrieves details for the Trello board associated with a specific action ID, returning board information only.
- [get_actions_by_id_action](get_actions_by_id_action.json): Retrieves detailed information about a specific Trello action by its ID.
- [get_actions_card_by_id_action](get_actions_card_by_id_action.json): Retrieves Trello card details for a given `idAction`, which must be an action specifically linked to a card; returns only card data, not action details.
- [get_actions_display_by_id_action](get_actions_display_by_id_action.json): Retrieves a display-friendly representation of an existing and accessible Trello action for UI/report purposes, providing presentation-focused data instead of full raw details and without altering the action.
- [get_actions_entities_by_id_action](get_actions_entities_by_id_action.json): Retrieves all entities (e.g., boards, lists, cards, members) associated with a specific, existing Trello action ID.
- [get_actions_list_by_id_action](get_actions_list_by_id_action.json): Retrieves the Trello list associated with a specific Trello action ID, for actions linked to a list.
- [get_actions_member_by_id_action](get_actions_member_by_id_action.json): Retrieves the Trello member who was the subject of an action (not the creator). This endpoint returns information about the member who was acted upon in actions like: - addMemberToCard: Returns the member who was added to a card - removeMemberFromCard: Returns the member who was removed from a card - addMemberToBoard: Returns the member who was added to a board Note: For actions that don't involve a member as a subject (e.g., createCard, createBoard), this endpoint returns 404. Use /actions/{idAction}/memberCreator to get the action's creator instead.
- [get_actions_member_creator_by_id_action](get_actions_member_creator_by_id_action.json): Retrieves details about the Trello member who created the action with the given `idAction`.
- [get_actions_organization_by_id_action](get_actions_organization_by_id_action.json): Fetches the organization details for a given Trello action, if the action has an associated organization.
- [get_actions_reactions_by_id](get_actions_reactions_by_id.json): Retrieves detailed information about a specific reaction on a Trello action. Use when you need to get the member and emoji details for a specific reaction by its ID.
- [get_actions_reactions_by_id_action](get_actions_reactions_by_id_action.json): Tool to list reactions for a specific action. Use when you need to retrieve emoji reactions and the members who added them to an action.
- [get_batch](get_batch.json): Executes multiple Trello API GET requests in a single batch operation for efficient bulk data retrieval.
- [get_boards_actions_by_id_board](get_boards_actions_by_id_board.json): Retrieves actions (e.g., card creations, comments) for a Trello board by its ID, useful for activity tracking; the board must exist.
- [get_boards_board_stars_by_id_board](get_boards_board_stars_by_id_board.json): Retrieves board stars (user-marked favorites) for a specified Trello board, with a filter for the current user's stars or other board-star results.
- [get_boards_by_id_board](get_boards_by_id_board.json): Fetches comprehensive details for a specific Trello board by its ID; this is a read-only action.
- [get_boards_cards_by_id_board](get_boards_cards_by_id_board.json): Retrieves cards from an existing Trello board, allowing filtering and customization of fields for cards, attachments, and members.
- [get_boards_cards_by_id_board_by_filter](get_boards_cards_by_id_board_by_filter.json): Retrieves cards from a specified Trello board, filtered by 'all' (all cards), 'closed' (archived only), 'open' (non-archived), or 'visible' (cards on non-archived lists).
- [get_boards_cards_by_id_board_by_id_card](get_boards_cards_by_id_board_by_id_card.json): Retrieves details for a specific Trello card by its ID and its parent board's ID, with options to customize returned fields for the card and associated data like attachments, actions, members, and checklists.
- [get_boards_checklists_by_id_board](get_boards_checklists_by_id_board.json): Retrieves checklists (primarily structure/metadata, not detailed item history) from a Trello board, with options to include associated card and check item details and to control which fields are returned for each entity.
- [get_boards_labels_by_id_board](get_boards_labels_by_id_board.json): Fetches labels for a specified Trello board, aiding in its organization or label management; this action does not detail per-card label usage.
- [get_boards_labels_by_id_board_by_id_label](get_boards_labels_by_id_board_by_id_label.json): Fetches specified fields for a specific label on a Trello board; this read-only action does not return information about which cards the label is attached to.
- [get_boards_lists_by_id_board](get_boards_lists_by_id_board.json): Retrieves lists from a specified Trello board, with options to filter lists and include card details. You can select which list and card fields to return.
- [get_boards_members_by_id_board](get_boards_members_by_id_board.json): Retrieves members of a Trello board, with options to filter the list and select specific member fields to return.
- [get_boards_members_cards_by_id_board_by_id_member](get_boards_members_cards_by_id_board_by_id_member.json): Retrieves cards for a member on a board, with options to customize returned fields and related data; member must have board access.
- [get_boards_members_invited_by_id_board](get_boards_members_invited_by_id_board.json): Retrieves a list of members invited to a specific Trello board who have not yet joined. A 404 response is returned as an empty member list.
- [get_boards_memberships_by_id_board](get_boards_memberships_by_id_board.json): Retrieves Trello board memberships (user roles and permissions) for auditing access or managing collaboration, returning only membership data and not other board content.
- [get_boards_memberships_by_id_board_by_id_membership](get_boards_memberships_by_id_board_by_id_membership.json): Retrieves a specific membership on a Trello board by its ID.
- [get_boards_organization_by_id_board](get_boards_organization_by_id_board.json): Fetches information about the Trello Workspace (organization) to which a specific board belongs, returning details for the Workspace only, not the board itself or its content.
- [get_cards_actions_by_id_card](get_cards_actions_by_id_card.json): Retrieves the history of actions (e.g., comments, updates, moves) for a Trello card specified by `idCard`; the card must exist and very old actions might not be available.
- [get_cards_attachments_by_id_card](get_cards_attachments_by_id_card.json): Retrieves attachments for a Trello card.
- [get_cards_attachments_by_id_card_by_id_attachment](get_cards_attachments_by_id_card_by_id_attachment.json): Retrieves a specific attachment from a Trello card by card ID and attachment ID.
- [get_cards_board_by_id_card](get_cards_board_by_id_card.json): Fetches detailed information about the Trello board to which a specific, existing, and accessible card belongs, using the card's ID or short link.
- [get_cards_by_id_card](get_cards_by_id_card.json): Retrieves a Trello card by its ID or shortlink, with options to include related data like actions, attachments, members, and checklists.
- [get_cards_check_item](get_cards_check_item.json): Tool to retrieve a specific checkItem on a card. Use when you need to check the status or details of a specific item in a card's checklist.
- [get_cards_check_item_states_by_id_card](get_cards_check_item_states_by_id_card.json): Gets the completed checklist items on a Trello card. Note: This endpoint only returns check items marked as 'complete', not incomplete items. Returns item IDs and states, not full checklist or card details.
- [get_cards_checklists_by_id_card](get_cards_checklists_by_id_card.json): Retrieves checklists for a Trello card identified by ID or shortlink, with options to filter checklists and include their check items.
- [get_cards_list_by_id_card](get_cards_list_by_id_card.json): Gets the Trello list to which a specified card (which must exist) belongs.
- [get_cards_members_by_id_card](get_cards_members_by_id_card.json): Retrieves members of a Trello card, identified by its ID or shortLink, allowing customization of which member fields are returned.
- [get_cards_members_voted_by_id_card](get_cards_members_voted_by_id_card.json): Fetches members who voted on a Trello card; requires an existing card ID, the Voting Power-Up to be active on the board, and members to have voted; returns member details, not vote counts.
- [get_check_item_by_id](get_check_item_by_id.json): Retrieves a specific check item from a checklist using the checklist ID and check item ID.
- [get_checklists_board_by_id_checklist](get_checklists_board_by_id_checklist.json): Retrieves the Trello board associated with a checklist ID. You can request all board fields or select specific fields.
- [get_checklists_by_id_checklist](get_checklists_by_id_checklist.json): Fetches a Trello checklist by its `idChecklist`, requiring the ID to refer to an existing checklist, and allows specifying which details of the checklist, its cards, and check items are returned.
- [get_checklists_cards_by_id_checklist](get_checklists_cards_by_id_checklist.json): Retrieves cards associated with a specific, valid Trello checklist ID, allowing for filtering and customization of card and related entity data fields.
- [get_checklists_check_items_by_id_checklist](get_checklists_check_items_by_id_checklist.json): Retrieves all check items from a Trello checklist. Returns item details including name, position, completion state, and optionally due dates and assigned members.
- [get_labels_board_by_id_label](get_labels_board_by_id_label.json): Retrieves the Trello board to which a given, valid Trello label ID (`idLabel`) belongs.
- [get_labels_by_id_label](get_labels_by_id_label.json): Retrieves detailed information for a specific Trello label by its ID, allowing selection of specific fields to return.
- [get_lists_actions_by_id_list](get_lists_actions_by_id_list.json): Retrieves actions for a Trello list by ID, such as card movements or comments, newest first. Results are paginated, with a default limit of five actions per page.

IMPORTANT LIMITATIONS: - Search indexing has a delay: newly created/updated cards may not appear for several minutes. - For exact name matching or time-sensitive lookups, use trello.get_lists_cards_by_id_list or trello.get_boards_cards_by_id_board to enumerate cards directly, then filter by name. - The search uses word tokenization: queries like 'Payment failed when sending tips' are split into individual terms ['Payment', 'failed', 'when', 'sending', 'tips'].
