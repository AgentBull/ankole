# linear operations

Choose the operation below, then read only its linked contract.

- [create_issue_label](create_issue_label.json): Create an issue label.
- [delete_comment](delete_comment.json): Delete a comment by ID.
- [get_issue](get_issue.json): Read an issue by UUID or identifier.
- [get_issue_status](get_issue_status.json): Read a workflow state.
- [get_project](get_project.json): Read a project by UUID, name, or slug.
- [get_team](get_team.json): Read a team by ID or name.
- [get_user](get_user.json): Read a workspace member by ID, name, email, or me.
- [list_comments](list_comments.json): List comments for one issue, project, initiative, or project update.
- [list_cycles](list_cycles.json): List a team's cycles.
- [list_issue_labels](list_issue_labels.json): List workspace or team issue labels.
- [list_issue_statuses](list_issue_statuses.json): List the workflow states of a team.
- [list_issues](list_issues.json): Find issues with cursor pagination.
- [list_projects](list_projects.json): List projects with cursor pagination.
- [list_teams](list_teams.json): Find teams in the connected workspace.
- [list_users](list_users.json): Find members of the connected workspace.
- [save_comment](save_comment.json): Create or update a comment; use id for an edit and a parent resource for a new comment.
- [save_issue](save_issue.json): Create or update an issue. Supply id to update; supply title and team to create.
- [save_project](save_project.json): Create or update a project. Supply id to update; supply name and teams to create.
