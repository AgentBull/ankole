# google_analytics operations

Choose the operation below, then read only its linked contract.

- [archive_custom_dimension](archive_custom_dimension.json): Tool to archive a CustomDimension on a property. Use when you need to remove a custom dimension from active use without permanently deleting it. Archived dimensions cannot be used in new reports.
- [batch_run_pivot_reports](batch_run_pivot_reports.json): Tool to return multiple pivot reports in a batch for a GA4 property. Use when you need to fetch multiple pivot table reports with multi-dimensional analysis in a single request.
- [batch_run_reports](batch_run_reports.json): Runs multiple analytics data reports for one GA4 property in a single request. Report metadata returned by this tool does not include data truncation reasons.
- [check_compatibility](check_compatibility.json): Tool to list dimensions and metrics compatible with a GA4 report request. Use when you need to validate compatibility of chosen dimensions or metrics before running a report.
- [create_audience_export](create_audience_export.json): Tool to create an audience export for Google Analytics. Use when you need to export a snapshot of users in an audience at a specific point in time. This initiates a long-running asynchronous request that returns an operation resource name immediately. The export begins in CREATING state with rowCount=0; the operation must complete before export data is accessible for querying.
- [create_audience_list](create_audience_list.json): Tool to create an audience list for later retrieval by initiating a long-running asynchronous request. Use when you need to create a snapshot of users currently in an audience. The method returns quickly with an Operation resource while processing occurs in the background.
- [create_custom_dimension](create_custom_dimension.json): Tool to create a CustomDimension for a Google Analytics property. Use when you need to add a new custom dimension to track specific user properties, event parameters, or eCommerce item parameters.
- [create_custom_metric](create_custom_metric.json): Tool to create a custom metric in Google Analytics. Use when you need to define a new custom metric for tracking specific event parameters.
- [create_expanded_data_set](create_expanded_data_set.json): Create an expanded data set for a Google Analytics 360 property using specified dimensions and metrics.
- [create_recurring_audience_list](create_recurring_audience_list.json): Tool to create a recurring audience list that automatically generates new audience lists daily based on the latest data. Use when you need to automate audience list creation and reduce quota token consumption.
- [create_report_task](create_report_task.json): Tool to create a report task as a long-running asynchronous request for customized Google Analytics event data reports. Use when you need to generate large or complex reports that process asynchronously.
- [create_rollup_property](create_rollup_property.json): Tool to create a roll-up property. Use when consolidating multiple GA4 properties into one aggregated view.
- [get_account](get_account.json): Tool to retrieve a single Account by its resource name. Use when you need detailed account info after confirming the account resource name (e.g., accounts/100).
- [get_attribution_settings](get_attribution_settings.json): Tool to retrieve attribution configuration for a Google Analytics property. Use when you need to check attribution models, lookback windows, and conversion export settings.
- [get_audience](get_audience.json): Tool to retrieve a single Audience configuration from a Google Analytics property. Use when you need detailed audience information including membership criteria and filter clauses.
- [get_audience_export](get_audience_export.json): Tool to get configuration metadata about a specific audience export. Use when you need to understand an audience export after it has been created or check its status.
- [get_audience_list](get_audience_list.json): Tool to get configuration metadata about a specific audience list. Use after confirming the audience list resource name.
- [get_custom_dimension](get_custom_dimension.json): Tool to retrieve a single CustomDimension by its resource name. Use when you need detailed information about a specific custom dimension including its display name, scope, and parameter name.
- [get_data_retention_settings](get_data_retention_settings.json): Tool to retrieve data retention configuration for a Google Analytics property. Use when you need to check event-level and user-level data retention durations and reset settings.
- [get_data_sharing_settings](get_data_sharing_settings.json): Tool to retrieve data sharing configuration for a Google Analytics account. Use when you need to check which data sharing settings are enabled for an account, including sharing with Google support, sales teams, products, and benchmarking.
- [get_google_signals_settings](get_google_signals_settings.json): Tool to retrieve Google Signals configuration settings for a GA4 property. Use when you need to check whether Google Signals is enabled and the consent status for a property.
- [get_key_event](get_key_event.json): Retrieve a Key Event by its resource name. This operation is read-only.
- [get_metadata](get_metadata.json): Tool to get metadata for dimensions, metrics, and comparisons for a GA4 property. Use to discover available fields before building a report — always derive dimension/metric apiNames from this output rather than hardcoding from GA4 UI labels, which differ. Available fields vary per property; skip validation and downstream report tools like google_analytics.run_report return 400 INVALID_ARGUMENT on incompatible or invalid field combinations. Response can contain hundreds of fields; filter to relevant subset before passing to downstream logic.
- [get_property](get_property.json): Tool to retrieve a single GA4 Property by its resource name. Use when you need detailed property configuration including display name, time zone, currency, and other settings.
- [get_property_quotas_snapshot](get_property_quotas_snapshot.json): Tool to retrieve all property quotas organized by category (corePropertyQuota, funnelPropertyQuota, realtimePropertyQuota) for a given GA4 property. Use when you need to check current quota usage. Snapshot data can lag real consumption by several minutes; treat reported values as approximate and avoid scheduling high-volume jobs at full apparent capacity.
- [get_recurring_audience_list](get_recurring_audience_list.json): Tool to get configuration metadata about a specific recurring audience list. Use when you need to understand a recurring audience list's state after it has been created or to get the resource name of the most recent audience list instance.
- [get_report_task](get_report_task.json): Tool to get report metadata about a specific report task. Use after creating a report task to check its processing state or inspect its report definition.
- [list_account_summaries](list_account_summaries.json): Tool to retrieve summaries of all Google Analytics accounts accessible by the caller. Use when you need a high-level overview of accounts and their properties without fetching full account details.
- [list_accounts_v1_beta](list_accounts_v1_beta.json): List Google Analytics accounts accessible to the caller using the v1beta API. Results are paginated and may include accounts without GA properties; soft-deleted accounts are excluded by default.
- [list_adsense_links](list_adsense_links.json): Lists a page of AdSense links for a Google Analytics property. Use the returned next-page token to retrieve additional pages.
- [list_audience_exports](list_audience_exports.json): Tool to list all audience exports for a property. Use when you need to find and reuse existing audience exports rather than creating new ones.
- [list_audience_lists](list_audience_lists.json): Tool to list all audience lists for a specified property to help find and reuse existing lists. Use when you need to retrieve a property's configured audience lists after confirming the property ID.
- [list_audiences](list_audiences.json): List audience configurations for a Google Analytics property; audiences created before 2020 may not be supported. Returned filter clauses include their types but not the full membership criteria.
- [list_bigquery_links](list_bigquery_links.json): Tool to list BigQuery Links on a property. Use when you need to retrieve BigQuery link resources associated with a Google Analytics property. Results support pagination for large datasets.
- [list_calculated_metrics](list_calculated_metrics.json): List Calculated Metrics
- [list_channel_groups](list_channel_groups.json): Tool to list ChannelGroups on a property. Use when you need to retrieve channel groups that categorize traffic sources in Analytics reports.
- [list_conversion_events](list_conversion_events.json): Lists deprecated conversion event resources configured for a Google Analytics property. Google recommends using key events instead.
- [list_custom_dimensions](list_custom_dimensions.json): List Custom Dimensions
- [list_custom_metrics](list_custom_metrics.json): Tool to list CustomMetrics on a property. Use when you need to retrieve all custom metrics configured for a given property.
- [list_data_streams](list_data_streams.json): Tool to list DataStreams on a property. Use when you need to retrieve data stream configurations for a Google Analytics property.
- [list_dv360_ad_links](list_dv360_ad_links.json): Tool to list Display & Video 360 advertiser links on a property. Use when you need to retrieve DisplayVideo360AdvertiserLink resources associated with a Google Analytics property. Results support pagination for large datasets.
- [list_dv360_link_proposals](list_dv360_link_proposals.json): Tool to list DisplayVideo360AdvertiserLinkProposals on a property. Use when you need to retrieve Display & Video 360 advertiser link proposals associated with a Google Analytics property. Results support pagination for large datasets.
- [list_event_create_rules](list_event_create_rules.json): Tool to list EventCreateRules configured on a web data stream. Use when you need to retrieve event create rules for a specific GA4 property data stream.
- [list_expanded_data_sets](list_expanded_data_sets.json): Tool to list ExpandedDataSets on a property. Use when you need to retrieve expanded data set configurations for a Google Analytics 360 property.
- [list_firebase_links](list_firebase_links.json): Tool to list FirebaseLinks on a property. Use when you need to retrieve Firebase connections associated with a Google Analytics property. Each property can have at most one FirebaseLink.
- [list_google_ads_links](list_google_ads_links.json): Tool to list GoogleAdsLinks on a property. Use when you need to retrieve Google Ads account links configured for a Google Analytics property. Supports pagination for large result sets.
- [list_key_events](list_key_events.json): List key event definitions for a Google Analytics property. Results are paginated, with a next-page token when more results are available.
- [list_measurement_protocol_secrets](list_measurement_protocol_secrets.json): Tool to list MeasurementProtocolSecrets under a data stream. Use when you need to retrieve measurement protocol secrets for server-side event tracking.
- [list_properties_filtered](list_properties_filtered.json): Tool to list GA4 properties based on filter criteria. Use when you need to find properties under a specific parent account or with specific firebase projects. Supports pagination and including soft-deleted properties.
- [list_recurring_audience_lists](list_recurring_audience_lists.json): List a page of recurring audience lists for a GA4 property, with a continuation token when more results are available. Use it to find existing recurring audience lists.
- [list_report_tasks](list_report_tasks.json): List a page of report tasks for a Google Analytics property, including task definitions and execution status. A continuation token can be used to retrieve subsequent pages.
- [list_reporting_data_annotations](list_reporting_data_annotations.json): List a page of Reporting Data Annotations for a specific GA4 property, optionally filtering the results. Annotations document important events or periods in reporting data.
- [list_search_ads360_links](list_search_ads360_links.json): Tool to list all SearchAds360Links on a property. Use when you need to retrieve all Search Ads 360 links for a given Google Analytics property. Supports pagination for large result sets.
- [list_sk_ad_network_conversion_value_schemas](list_sk_ad_network_conversion_value_schemas.json): Tool to list SKAdNetworkConversionValueSchema configurations for an iOS data stream. Use when you need to retrieve conversion value schemas for iOS app tracking. Maximum one schema per property is supported.
- [list_subproperty_event_filters](list_subproperty_event_filters.json): List a page of subproperty event filters on a property, including filters that route events to subproperties. Use the returned page token to retrieve subsequent pages.
- [list_subproperty_sync_configs](list_subproperty_sync_configs.json): Tool to list SubpropertySyncConfig resources for managing subproperty synchronization configurations. Use when you need to fetch subproperty sync configs for a GA4 property.
- [provision_account_ticket](provision_account_ticket.json): Tool to request a ticket for creating a Google Analytics account. Use when you need to initiate the account creation flow that requires user acceptance of Terms of Service.
- [query_audience_export](query_audience_export.json): Tool to query a completed audience export. Use when you need to fetch user rows with pagination.
- [query_audience_list](query_audience_list.json): Tool to query an audience list. Use when you need to retrieve user rows from a GA4 audience list with pagination.
- [query_report_task](query_report_task.json): Tool to retrieve a report task's content. Use this after creating a report task with CreateReportTask and confirming it is in ACTIVE state. This method returns an error if the report task's state is not ACTIVE.
- [run_funnel_report](run_funnel_report.json): Tool to run a GA4 funnel report. Use when you need a customized funnel analysis report for a given property. Funnel step sequence is determined by step attributes in the response, not row order.
- [run_pivot_report](run_pivot_report.json): Tool to run a customized pivot report of Google Analytics event data. Use when you need a pivot table view with advanced segmentation and multi-dimensional analysis of GA4 data.
- [run_realtime_report](run_realtime_report.json): Tool to run a customized realtime report of Google Analytics event data. Use when you need realtime data (last 30-60 minutes) with dimensions and metrics for a GA4 property.
- [run_report](run_report.json): Run a customized GA4 event-data report for a property using dimensions, metrics, filters and date ranges or a cohort specification. Requests can include up to 9 dimensions and 10 metrics, with offset and limit for pagination. Dimensions, metrics and filters must be compatible; use google_analytics.check_compatibility to check combinations. The invalid `dateRange` dimension is removed from requests; use a date dimension for date-based grouping.
- [send_events](send_events.json): Send GA4 web-stream events using the Measurement Protocol and an API secret. A successful response indicates HTTP receipt, not that Google Analytics processed the events.
- [update_property](update_property.json): Tool to update an existing GA4 Property. Use when you need to modify property settings such as display name, time zone, currency code, or industry category.
- [validate_events](validate_events.json): Validate Measurement Protocol events for a web stream before sending them to production, checking event structure and parameters.
