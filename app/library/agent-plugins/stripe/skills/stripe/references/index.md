# stripe operations

Choose the operation below, then read only its linked contract.

- [add_invoice_lines](add_invoice_lines.json): Tool to add multiple line items to a draft Stripe invoice. Use when you need to add additional charges, services, or credits to an existing invoice that is still in draft status.
- [attach_invoice_payment](attach_invoice_payment.json): Attaches a PaymentIntent or Out of Band Payment to an invoice's payments list. When the PaymentIntent status changes to succeeded, the payment is credited to the invoice. Use when you need to associate an existing payment with a specific invoice.
- [attach_payment_method](attach_payment_method.json): Attaches a PaymentMethod to a Customer. Use when you need to save a payment method for future use with a specific customer. The PaymentMethod must be in a detached state before attaching.
- [cancel_payment_intent](cancel_payment_intent.json): Cancels a PaymentIntent when in cancelable state. Use when a PaymentIntent is no longer needed to prevent further charges. For PaymentIntents with status='requires_capture', the remaining amount_capturable will be automatically refunded.
- [cancel_subscription](cancel_subscription.json): Cancels a customer's Stripe subscription immediately, with options to invoice for metered usage and prorate charges for unused time.
- [cancel_subscription_schedule](cancel_subscription_schedule.json): Cancels a subscription schedule and its associated subscription immediately if active. Only schedules with status 'not_started' or 'active' can be canceled.
- [capture_charge](capture_charge.json): Tool to capture payment on an uncaptured charge. Use when a charge was created with capture=false and you're ready to capture the payment.
- [capture_payment_intent](capture_payment_intent.json): Captures the funds of an existing uncaptured PaymentIntent. Use when the PaymentIntent status is 'requires_capture'.
- [close_dispute](close_dispute.json): Tool to close a dispute. Use when you want to dismiss a dispute and acknowledge it as lost, indicating no evidence will be submitted. This action is irreversible.
- [confirm_payment_intent](confirm_payment_intent.json): Tool to confirm customer intent to pay with current or provided payment method. Use when ready to finalize a PaymentIntent and initiate the payment attempt. A return_url is required if confirmation needs customer action like 3D Secure authentication.
- [create_charge_refund](create_charge_refund.json): Tool to create a refund for a charge in Stripe. Use when you need to refund a previously created charge fully or partially.
- [create_checkout_session](create_checkout_session.json): Tool to create a Stripe Checkout Session. Use when you need a secure, hosted URL to collect payments or subscriptions via Stripe Checkout.
- [create_coupon](create_coupon.json): Creates a new discount coupon in Stripe with percentage or fixed amount discount. Use when creating promotional discounts for customers.
- [create_customer](create_customer.json): Creates a new customer in Stripe, required for creating charges or subscriptions; an email is highly recommended for customer communications.
- [create_customer_session](create_customer_session.json): Creates a Stripe Customer Session for client-side access to configured components, such as the Payment Element or customer sheet.
- [create_invoice](create_invoice.json): Creates a new draft Stripe invoice for a customer; use to revise an existing invoice, bill for a specific subscription (which must belong to the customer), or apply detailed customizations. Note: Stripe API enforces a maximum value of 99,999,999 (in smallest currency unit) for amount fields including `unit_amount` in invoice items, `application_fee_amount`, and `transfer_data.amount`. Values exceeding this limit will be rejected.
- [create_invoice_item](create_invoice_item.json): Tool to create an invoice item for draft invoices. Use when adding line items to customer invoices before finalization.
- [create_payment_intent](create_payment_intent.json): Creates a Stripe PaymentIntent to initiate and process a customer's payment; using `application_fee_amount` for a connected account requires the `Stripe-Account` header.
- [create_payment_link](create_payment_link.json): Tool to create a Stripe Payment Link. Use when you need to generate a hosted checkout page URL that can be shared with customers to collect payments without building custom checkout infrastructure. Supports up to 20 line items per payment link.
- [create_payment_method](create_payment_method.json): Creates a PaymentMethod object representing a customer's payment instrument (card, bank account, etc.). PaymentMethods can be: - Attached to a Customer for future use - Used directly with PaymentIntents to collect payments - Stored for recurring payments or subscriptions The 'type' parameter determines which payment-specific fields are required: - type='card': requires card object with number, exp_month, exp_year - type='sepa_debit': requires sepa_debit object with iban - type='us_bank_account': requires us_bank_account object with account details - And many other payment method types (acss_debit, au_becs_debit, bacs_debit, boleto, etc.) IMPORTANT: For card payments, collecting card numbers directly via API requires PCI compliance and special account permissions. Consider using Stripe.js, Stripe Elements, or mobile SDKs instead for better security and easier PCI compliance. This action is most useful for non-card payment methods or when you have explicit authorization for raw card data access.
- [create_preview_invoice](create_preview_invoice.json): Tool to preview an upcoming invoice without creating it. Use when you need to show pending charges, renewal fees, discounts, and prorations before finalizing an invoice.
- [create_price](create_price.json): Creates a new Stripe Price for a product, defining its charges (one-time or recurring) and billing scheme; requires either an existing `product` ID or `product_data`.
- [create_product](create_product.json): Creates a new product in Stripe, encoding the request as `application/x-www-form-urlencoded` by flattening nested structures.
- [create_promotion_code](create_promotion_code.json): Tool to create a promotion code linked to an underlying coupon. Use when you need to generate customer-redeemable codes with optional restrictions.
- [create_refund](create_refund.json): Creates a full or partial refund in Stripe, targeting either a specific charge ID or a payment intent ID.
- [create_subscription](create_subscription.json): Creates a new, highly configurable subscription for an existing Stripe customer, supporting multiple items, trials, discounts, and various billing/payment options.
- [create_subscription_item](create_subscription_item.json): Tool to add a new item to an existing subscription without changing existing items. Use when adding a product or service to a customer's subscription.
- [create_subscription_schedule](create_subscription_schedule.json): Tool to create a new subscription schedule for managing subscription changes over time. Use when you need to schedule future subscription modifications, phase transitions, or automate subscription lifecycle management.
- [delete_coupon](delete_coupon.json): Tool to delete a coupon from Stripe. Use when you need to remove a coupon code, preventing new redemptions while preserving existing customer discounts.
- [delete_customers_customer](delete_customers_customer.json): Permanently deletes a customer and cancels active subscriptions. Use when you need to remove a customer record from your Stripe account. This operation is irreversible and automatically terminates any active subscriptions.
- [delete_invoice](delete_invoice.json): Permanently deletes a draft invoice. This action cannot be undone. Use when you need to remove a draft invoice. Finalized or subscription invoices must be voided instead.
- [delete_invoiceitem](delete_invoiceitem.json): Tool to delete an invoice item from Stripe. Use when removing invoice items that are not attached to invoices or attached to draft invoices.
- [delete_product](delete_product.json): Delete a product. Deleting a product is only possible if it has no prices associated with it. Products with type=good cannot be deleted if they have SKUs.
- [delete_subscription_discount](delete_subscription_discount.json): Removes the currently applied discount on a subscription, such as a discount code or promotion. The response may include a deletion confirmation flag.
- [delete_subscription_item](delete_subscription_item.json): Deletes a subscription item without canceling the subscription. Use when you need to remove a specific item from a customer's subscription while keeping the subscription active.
- [delete_v1_invoices_void_an_invoice](delete_v1_invoices_void_an_invoice.json): Tool to void a finalized Stripe invoice. Use when you need to permanently mark an invoice as void to prevent any further collection attempts. This action cannot be undone.
- [detach_payment_from_invoice](detach_payment_from_invoice.json): Tool to detach a payment from an invoice. Use when you need to remove a payment from an invoice's list of payments. Only works with paid or canceled PaymentIntents.
- [detach_payment_method](detach_payment_method.json): Detaches a PaymentMethod object from a Customer account. Use when you need to remove a payment method from a customer without deleting it entirely.
- [expire_checkout_session](expire_checkout_session.json): Tool to expire an active Stripe Checkout Session. Use when you need to prevent customers from completing an open checkout session.
- [finalize_invoice](finalize_invoice.json): Finalize a draft invoice so it becomes open/collectable (and immutable where required). Use when you need to transition an invoice from draft to open status for payment collection.
- [get_balance_settings](get_balance_settings.json): Tool to retrieve balance settings for a Stripe account. Use when you need to fetch configuration options for customizing account balances and payout settings for a connected account or the authenticated account.
- [get_balance_transaction](get_balance_transaction.json): Retrieves the balance transaction with the given ID. Use when you need detailed information about a specific balance transaction including amounts, fees, availability dates, and transaction sources.
- [get_billing_credit_balance_summary](get_billing_credit_balance_summary.json): Retrieves the credit balance summary for a customer in Stripe Billing. This action returns the available and ledger balances for billing credits granted to a customer. You can filter by a specific credit grant, price type (metered), specific prices, or billable items. The balance summary includes one entry per currency used in the credit grants. Use Cases: - Check remaining billing credits for a customer - View credit balances for specific metered prices or products - Monitor available vs. ledger balance for billing credits - Track credit usage across different currencies
- [get_billing_credit_balance_transactions_id](get_billing_credit_balance_transactions_id.json): Retrieves a credit balance transaction by its unique identifier. Use when you need to get details about a specific credit or debit transaction against a credit grant.
- [get_charges_charge_dispute](get_charges_charge_dispute.json): Tool to retrieve a dispute for a specified charge. Use when you need to get dispute details associated with a specific charge ID.
- [get_charges_charge_refunds_refund](get_charges_charge_refunds_refund.json): Tool to retrieve the details of an existing refund within a specific charge. Use when you need to get refund information using both the charge ID and refund ID.
- [get_checkout_sessions_session_line_items](get_checkout_sessions_session_line_items.json): Tool to retrieve line items for a Checkout Session. Use when you need to view the items, pricing, quantities, and totals for a specific checkout session.
- [get_climate_products_product](get_climate_products_product.json): Tool to retrieve details of a specific Stripe Climate product. Use when you need to get information about a particular carbon removal product including pricing and supplier details.
- [get_coupon](get_coupon.json): Retrieves full details for an existing Stripe coupon using its unique ID. Use when you need to check coupon validity, discount details, or redemption limits.
- [get_customers_customer_payment_methods](get_customers_customer_payment_methods.json): Retrieves a list of payment methods for a given customer, supporting type filtering and pagination.
- [get_customers_customer_payment_methods_payment_method](get_customers_customer_payment_methods_payment_method.json): Tool to retrieve a specific PaymentMethod object for a given Customer. Use when you need to get detailed information about a particular payment method associated with a customer.
- [get_invoice_payments_id](get_invoice_payments_id.json): Tool to retrieve details of a specific Stripe invoice payment by ID. Use when you need to get information about an existing invoice payment.
- [get_invoiceitems_invoiceitem](get_invoiceitems_invoiceitem.json): Tool to retrieve the details of an invoice item using its unique identifier. Use when you need to fetch information about a specific invoice item.
- [get_invoices_invoice](get_invoices_invoice.json): Tool to retrieve a specific invoice by ID. Use when you need to get detailed information about an existing invoice.
- [get_invoices_invoice_lines](get_invoices_invoice_lines.json): Tool to retrieve a paginated list of line items for a specific invoice. Use when you need to see the individual charges, products, or services included in an invoice.
- [get_payment_intent_amount_details_line_items](get_payment_intent_amount_details_line_items.json): Tool to retrieve paginated line items for a PaymentIntent. Use when you need to get detailed product and service information including quantities, prices, discounts, and taxes for a specific payment intent.
- [get_payment_link](get_payment_link.json): Tool to retrieve details of an existing Stripe payment link by ID. Use when you need to get information about a specific payment link.
- [get_payment_links_payment_link_line_items](get_payment_links_payment_link_line_items.json): Tool to retrieve paginated line items for a payment link. Use when you need to get detailed product and service information including quantities, prices, discounts, and taxes for a specific payment link.
- [get_payment_method](get_payment_method.json): Retrieves the details of a PaymentMethod object by its unique identifier. Returns information including the payment method type (card, us_bank_account, sepa_debit, etc.), billing details, and type-specific payment information. Use this when you need to view the configuration and details of an existing payment method.
- [get_prices_price](get_prices_price.json): Retrieves detailed information for a specific Stripe price using its unique ID. Use when you need to fetch price details.
- [get_products_id](get_products_id.json): Retrieves detailed information for an existing Stripe product using its unique product ID. Use when you need to fetch details about a specific product.
- [get_promotion_codes](get_promotion_codes.json): Retrieves a list of promotion codes from a Stripe account with optional filters for active status, code value, coupon association, and customer restrictions. Supports cursor-based pagination.
- [get_refunds_refund](get_refunds_refund.json): Tool to retrieve details of a specific Stripe refund by ID. Use when you need to get information about an existing refund.
- [get_subscription](get_subscription.json): Retrieves detailed information for an existing Stripe subscription using its unique ID.
- [get_subscription_item](get_subscription_item.json): Retrieves detailed information for a specific subscription item using its unique ID. Use when you need to fetch subscription item details, pricing, or billing information.
- [get_subscription_schedules_schedule](get_subscription_schedules_schedule.json): Retrieve a subscription schedule using its unique identifier. Use when you need to view details of an existing schedule including phases, settings, and status.
- [get_upcoming_invoice_line_items](get_upcoming_invoice_line_items.json): Tool to retrieve a paginated list of line items for an upcoming invoice preview. Use when you need to see detailed line items before an invoice is finalized.
- [list_all_subscription_item_period_summaries](list_all_subscription_item_period_summaries.json): Lists a page of legacy usage record summaries for a subscription item across billing periods, with cursor pagination. DEPRECATED: Stripe removed this endpoint in Basil; legacy usage requires a pre-Basil API version. Migrate to Stripe meters for usage-based billing.
- [list_balance_transactions](list_balance_transactions.json): Lists a page of balance transactions for the connected Stripe account. Supports filtering by date range, currency, type, payout, or source, as well as cursor-based pagination.
- [list_billing_credit_balance_transactions](list_billing_credit_balance_transactions.json): List billing credit balance transactions for a customer or customer account, with pagination and optional credit grant filtering. Use to view credit and debit transactions and track billing credit activity.
- [list_charge_refunds](list_charge_refunds.json): Lists refunds for a specific Stripe charge, ordered by creation time descending. Results are paginated and can be used to track refund history and audit transactions.
- [list_charges](list_charges.json): Retrieves a list of Stripe charges with filtering and pagination; use valid cursor IDs from previous responses for pagination, and note that charges are typically returned in reverse chronological order.
- [list_checkout_sessions](list_checkout_sessions.json): Tool to retrieve a list of Stripe Checkout Sessions with pagination support. Use when you need to list checkout sessions, optionally filtering by customer, status, payment intent, or other criteria.
- [list_climate_products](list_climate_products.json): Lists Stripe Climate carbon removal products with supplier information and USD pricing per metric ton. Results are paginated.
- [list_coupons](list_coupons.json): Retrieves a list of discount coupons from a Stripe account, supporting pagination via `limit`, `starting_after`, and `ending_before`.
- [list_customers](list_customers.json): Retrieves a list of Stripe customers, with options to filter by email, creation date, or test clock, and support for pagination.
- [list_disputes](list_disputes.json): Tool to list all disputes from a Stripe account. Use when you need to retrieve disputes with optional filtering by charge or payment intent.
- [list_invoice_payments](list_invoice_payments.json): Tool to list all payments for invoices in Stripe. Use when you need to retrieve payment information associated with invoices, including pagination and filtering by invoice ID, status, or creation date.
- [list_invoiceitems](list_invoiceitems.json): Retrieves a paginated list of Stripe invoice items. Use to filter by customer, invoice, creation date, or attachment status with cursor-based pagination.
- [list_invoices](list_invoices.json): Retrieves a list of Stripe invoices, filterable by various criteria and paginatable using invoice ID cursors obtained from previous responses.
- [list_payment_intents](list_payment_intents.json): Tool to list PaymentIntents from Stripe. Use when you need to retrieve a list of payment intents with optional filtering by customer, creation date, or pagination parameters.
- [list_payment_links](list_payment_links.json): Retrieves a list of payment links from Stripe, sorted by creation date in descending order by default.
- [list_prices](list_prices.json): Tool to list Stripe prices. Use when you need to retrieve and filter price objects before processing write operations.
- [list_products](list_products.json): Retrieves a list of Stripe products, with optional filtering and pagination; `starting_after`/`ending_before` cursors must be valid product IDs from a previous response.
- [list_promotion_codes](list_promotion_codes.json): Tool to retrieve a list of promotion codes from Stripe. Use when you need to view, filter, or paginate through promotion codes with optional filters for active status, code, coupon, customer, or creation date.
- [list_refunds](list_refunds.json): Lists Stripe refunds, sorted by creation date descending (newest first), with optional filtering by charge or payment_intent and pagination support.
- [list_subscription_items](list_subscription_items.json): Lists subscription items for a given Stripe subscription, with pagination. Items include pricing, quantities, and billing details.
- [list_subscriptions](list_subscriptions.json): Retrieves a list of Stripe subscriptions, optionally filtered by various criteria such as customer, price, status, collection method, and date ranges, with support for pagination.
- [mark_invoice_uncollectible](mark_invoice_uncollectible.json): Tool to mark a Stripe invoice as uncollectible for bad debt accounting purposes. Use when you need to write off an unpaid invoice that is unlikely to be collected.
- [migrate_subscription](migrate_subscription.json): Migrates a subscription from classic to flexible billing mode to enable flexible proration and invoice calculation. Requests use Stripe API version 2025-06-30.basil.
- [pay_invoice](pay_invoice.json): Tool to pay an invoice manually outside the normal collection schedule. Use when you need to manually trigger payment on an invoice or mark it as paid externally using paid_out_of_band parameter.
- [present_payment_method](present_payment_method.json): Tool to present a payment method on a simulated terminal reader for testing purposes. Use when testing payment flows, simulating card acceptance, or validating terminal reader integrations in test mode.
- [resume_subscription](resume_subscription.json): Resumes a paused Stripe subscription with billing cycle and proration options. Use when a customer wants to restart payment collection on a previously paused subscription.
- [retrieve_balance](retrieve_balance.json): Retrieves the complete current balance details for the connected Stripe account.
- [retrieve_charge](retrieve_charge.json): Retrieves full details for an existing Stripe charge using its unique ID.
- [retrieve_checkout_session](retrieve_checkout_session.json): Tool to retrieve a Checkout Session object from Stripe. Use when you need to get the current state of a checkout session, including payment status, customer details, and line items.
- [retrieve_customer](retrieve_customer.json): Retrieves detailed information for an existing Stripe customer using their unique customer ID.
- [retrieve_payment_intent](retrieve_payment_intent.json): Retrieves a PaymentIntent by its ID; `client_secret` is required if a publishable API key is used.
- [retrieve_promotion_code](retrieve_promotion_code.json): Tool to retrieve a Stripe promotion code by its ID. Use when you need to get details about a specific promotion code including its associated coupon, usage restrictions, and redemption statistics.
- [retrieve_upcoming_invoice](retrieve_upcoming_invoice.json): Tool to preview the upcoming invoice for a customer, showing all pending charges including subscription renewals and invoice items. Use when you need to preview invoice amounts before they are finalized, test the effects of subscription updates including prorations, or estimate future billing.
- [search_charges](search_charges.json): Search charges using Stripe's Search Query Language. Use when you need to find historical charges by status, amount, customer, metadata, or other criteria.
- [search_customers](search_customers.json): Retrieves a list of Stripe customers matching a search query that adheres to Stripe's Search Query Language.
- [search_invoices](search_invoices.json): Searches for invoices using Stripe's Search Query Language. Use when you need to find invoices by status, total amount, customer, currency, or other criteria. Data is typically searchable within one minute, though propagation can lag up to an hour during outages.
- [search_payment_intents](search_payment_intents.json): Searches for PaymentIntents using Stripe's Search Query Language. Use when you need to find payments by status, amount, customer, or other criteria.
- [search_prices](search_prices.json): Search for prices using Stripe's Search Query Language. Use when you need to find prices by status, currency, product, or other criteria with flexible query syntax.
- [search_products](search_products.json): Tool to search for products using Stripe's Search Query Language. Use when you need to find products based on specific criteria like active status, name, or metadata.
- [search_subscriptions](search_subscriptions.json): Searches for subscriptions using Stripe's Search Query Language. Use when you need to find subscriptions by status, metadata, created timestamp, or canceled_at timestamp.
- [send_invoice](send_invoice.json): Tool to manually send a finalized Stripe invoice to the customer outside the automatic billing schedule. Use when you need to deliver an invoice for manual payment. Note: In test mode, no emails are sent, but webhook events (invoice.sent) are still generated.
- [update_application_fee_refund](update_application_fee_refund.json): Updates metadata on an existing application fee refund identified by its fee ID and refund ID.
- [update_charge](update_charge.json): Tool to update a Stripe charge object with provided parameters. Use when you need to modify charge details such as description, metadata, fraud assessment, receipt email, shipping information, or transfer group.
- [update_charge_dispute](update_charge_dispute.json): Tool to update metadata on a charge's dispute. Use when you need to attach structured information to a dispute for tracking or internal reference purposes.
- [update_charge_refund](update_charge_refund.json): Tool to update a specified refund within a charge. Use when you need to modify the metadata of an existing refund.
- [update_checkout_session](update_checkout_session.json): Tool to update a Stripe Checkout Session dynamically. Use when you need to modify customer information, line items, or shipping options on an existing checkout session. Line item updates require retransmitting the entire array.
- [update_coupon](update_coupon.json): Updates a Stripe coupon's metadata, name, or currency options. Other coupon details (currency, duration, amount_off, percent_off) are, by design, not editable. Use when you need to modify coupon metadata, display name, or add new currency-specific discount amounts.
- [update_customer](update_customer.json): Updates an existing Stripe customer, identified by customer_id, with only the provided details; unspecified fields remain unchanged.
- [update_dispute](update_dispute.json): Tool to update a Stripe dispute by submitting evidence or updating metadata. Use when responding to payment disputes to provide documentation countering the dispute claim.
- [update_invoice](update_invoice.json): Updates a draft Stripe invoice. Use when modifying invoice details before finalization. Once finalized, monetary values and collection_method become immutable.
- [update_invoice_lines](update_invoice_lines.json): Bulk updates existing line items on a draft invoice, including descriptions, amounts, quantities and discounts. It can also update metadata on the invoice itself.
- [update_invoiceitem](update_invoiceitem.json): Updates an invoice item on a draft invoice. Use when modifying invoice item properties like amount, description, discounts, or tax settings before invoice finalization.
- [update_payment_intent](update_payment_intent.json): Updates a Stripe PaymentIntent with new values for specified parameters; note that if `currency` is updated, `amount` might also be required, and certain updates (e.g., to `payment_method`) can necessitate re-confirmation by the customer.
- [update_payment_link](update_payment_link.json): Updates an existing payment link with new configuration details. Use when modifying payment link settings, tax configurations, custom fields, metadata, or post-completion behavior.
- [update_payment_method](update_payment_method.json): Updates an existing PaymentMethod object in Stripe. Use when you need to modify billing details, expiration dates, or metadata for a payment method. The payment method must be attached to a customer before updates can be applied.
- [update_price](update_price.json): Updates a Stripe price by setting passed parameter values; unspecified parameters remain unchanged. Use when you need to modify price metadata, active status, lookup key, or nickname. Note: Price amounts cannot be modified via API.
- [update_product](update_product.json): Tool to update an existing product in Stripe. Use when you need to modify product details like name, description, pricing, or availability.
- [update_promotion_code](update_promotion_code.json): Updates an existing Stripe promotion code by setting the values of the parameters passed. Use when you need to activate/deactivate a promotion code, update its metadata, or modify redemption restrictions. Most promotion code fields are intentionally non-editable after creation.
- [update_subscription](update_subscription.json): Updates an existing, non-canceled Stripe subscription by its ID, including supported item, billing, payment, tax, cancellation, and metadata settings.
- [update_subscription_schedule](update_subscription_schedule.json): Tool to update an existing subscription schedule in Stripe. Use when you need to modify phases, default settings, metadata, or end behavior of a subscription schedule.
- [verify_microdeposits_payment_intent](verify_microdeposits_payment_intent.json): Verifies microdeposits on a PaymentIntent object by matching deposit amounts or descriptor code. Use after microdeposits are sent to complete bank account verification.
- [void_invoice](void_invoice.json): Voids a finalized Stripe invoice while maintaining a paper trail. Voiding is permanent and cannot be undone; draft invoices should be deleted instead.
