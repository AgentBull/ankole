需要制作配图、概念图或视觉草稿时，可以为 Agent 启用图像生成功能。配置完成后，用户直接在原有聊天窗口中提出需求，Agent 便会将生成的图片作为附件发回；若所选模型支持参考图，还可以让 Agent 在原图基础上继续修改。

## 选择执行路径

公共 `image_generation` 工具支持两条执行路径：

- **Hosted 路径：**配置 Agent 的 `image_generate` 模型档案。AIGateway 会调用该档案指定的独立提供商与模型生成图片，再将结果交回主模型。
- **原生路径：**不配置 `image_generate` 档案，改由声明支持原生图像生成的主提供商直接处理（OpenAI 与 ChatGPT 订阅均支持此路径）。此时，AIGateway 会将公共工具直接透传给主提供商。

由此可见，`image_generate` 控制的是路由方式，而非功能总开关。如果既未配置 `image_generate` 档案，主提供商也未声明支持原生图像生成，AIGateway 就会返回明确的配置错误。

按以下步骤配置 Hosted 路径：

1. 在 Console 的 **LLM Provider** 页面中，添加提供目标图像模型的提供商。
2. 打开**智能体**页面，选择目标 Agent。
3. 在模型档案中找到 `image_generate`。
4. 选择图像提供商与具体模型并保存。
5. 回到聊天渠道，向 Agent 发送明确的图像生成请求。

计费与用量统计彼此独立：主模型的 Token 用量计入主提供商凭据，图像生成的 Token 用量则计入实际执行出图的凭据；即使中途发生凭据池轮换，账目也不会混淆。

## 把要求写成一份视觉说明

图像生成请求不必长篇大论，但要交代清楚图片的用途、画面内容，以及哪些元素不可随意改动。先明确用途与主体，再补充构图、视觉风格和限制条件，效果远好于堆砌形容词。

可以参考以下五个维度组织说明，按需填写即可，不必面面俱到：

- **用途与画幅**：说明图片用于网页、演示文稿还是社交媒体，并给出横版、竖版、方形或具体比例。
- **主体与场景**：说清画面中的主角、所处环境以及正在发生的事。
- **构图与风格**：只写真正影响成片效果的视角、位置、留白、材质、光线或视觉媒介。
- **图片内文字**：将必须出现的原文放入引号并指明位置；若文字较长，建议留在图片外排版。
- **限制条件**：明确排除不希望出现的文字、水印、标志或物体；附带参考图时，也要写清哪些部分必须保持不变。

例如：

```text
用途：产品发布说明头图，16:9，网页标题将放在左侧。
主体：一台白色设备放在深蓝色桌面上，位于画面右侧。
画面：简洁的几何构图，柔和侧光，左侧保留大块空白。
文字：图片内只出现“ANKOLE 2.0”，位于右下角。
限制：不要人物、水印、其他品牌标志或额外文字。
```

不同模型对图中文字、画幅尺寸和参考图的处理能力有所差异，具体支持范围以当前模型及其提供商的说明为准。

## 在同一会话中逐步修改

图片往往很难一次成稿。建议先让 Agent 生成初稿确定大方向，再在同一会话中分步微调。每轮只调整一个问题或一组相关细节，不仅更容易把控效果，也无需从头重复整段需求。

修改现有图片时，请同时写清“要改哪里”和“哪些保持不变”。例如：

```text
只把背景改成浅灰色。主体、构图、光线、文字位置和颜色都保持不变。
```

如果上传了多张参考图，请用“图 1”“图 2”分别指明各自用途，例如沿用图 1 的主体、参考图 2 的配色。注意，这类请求需要当前模型本身支持参考图输入或图像编辑才会生效。

## 没有生成图片时

- **Agent 只回复了文字**：先确认客户端或 Agent 已开放 `image_generation` 工具，再检查是否已配置 `image_generate` 档案，或主提供商是否支持原生图像生成。
- **找不到可选模型**：当前已添加的提供商未提供图像生成模型，请添加支持该能力的提供商。
- **要求不受支持**：改用能力匹配的模型，或删去当前模型不支持的尺寸、格式、透明背景、参考图及编辑要求。
- **生成了图片，但内容不合预期**：通常并非配置问题，建议回到同一会话，明确指出需要修改和保留的部分。
- **生成成功但聊天中没有附件**：检查当前聊天渠道是否仍允许上传文件，并查看该次对话的错误信息。

可用的画幅尺寸、文件格式、透明背景、参考图及编辑能力，均以 Console 中所选模型及其提供商的说明为准。
