| 你看到的现象 | 先检查 |
|---|---|
| `/setup` 或 Console 打不开 | 部署环境、`control-plane`、`function-runtime`、PostgreSQL、域名解析与 HTTPS 证书 |
| Console 或 Pod 能打开，但登录失败或通讯录不完整 | 企业身份源（IdP SSO）、免密邮箱验证码（`SiteCredential`，配置于 `authn.email.mail`）、`principals.pod_login_policy` 登录策略，以及 `siteadmin` / `pod_admin` 管理员组成员关系 |
| Console 内 Agent 对话正常，但某个 IM 平台收不到消息 | 对应聊天渠道的平台配置与信号路由规则 |
| IM 消息已进入 Ankole，但 Agent 无法生成回复 | LLM Provider、Agent 模型档案与 Worker 运行状态 |
| 仅某一个外部平台异常 | 直接查看下方对应平台的排错标签页，切勿照搬其他平台的排查方法 |
