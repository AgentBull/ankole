Pod では、**チャット**（Chat）が人や Agent とのリアルタイムなやり取りを担い、**Jobs**（`/jobs`）がワークスペース内の非同期実行と定期スケジュールを 1 つのボードに集約します。単発のバックグラウンド Agent ジョブや複数ステップのワークフローから、定期実行の Cron スケジュール、「後で確認」タイマー、ページに紐づく Applet の自動化ジョブまで、次に予定されているもの・いま実行中または対応待ちのもの・完了したものが一目で把握できます。

## ボードを開く

Pod サイドバーの **ホーム** タブを開き、**共有アイテム** のすぐ上にある **Jobs** を選択します。`⌘K`（Windows・Linux では `Ctrl+K`）を押してコマンドメニューから **Jobs** に移動することもできます。

バックグラウンドで稼働中の項目があるとき、サイドバーの **Jobs** にはライブバッジが表示されます。

- **実行中** カラムに入力待ちや直近のエラーなど確認が必要な項目がある場合、アンバー色のバッジで件数を知らせます。
- 対応待ちの項目がなく実行が順調に進んでいる場合は、現在稼働している件数を情報バッジで表示します。

ボード上部のヘッダーには現在稼働中の Agent が表示され、**ボード表示** を **ステータス別** と **Agent 別** の間で切り替えられるほか、**フィルター** から担当 Agent（または **ページ自動化**）やカードの **種別** で絞り込めます。

## 単発ジョブと常駐ルーチン

ボードは **予定**・**実行中**・**完了** の 3 つのカラムで構成され、性質の異なる 2 種類のカードを扱います。

- **単発ジョブ**（**Agent ジョブ** と **ワークフロー**）は、開始から実行を経て、終了すると **完了** カラムへ移ります。完了したバックグラウンド Agent ジョブに追加の指示を送って継続実行した場合、Ankole は引き継ぎチェーン全体を 1 枚のカードにまとめるため、最初から最後まで 1 つの作業として追えます。
- **常駐ルーチン**（**Cron**、**自動化**、**後で確認**）は、継続的なスケジュールや Applet トリガー、時間差のリマインダーを表します。トリガーのたびに新しいカードが増えることはなく、1 つのルールが常に 1 枚のカードに対応します。Cron やページ自動化が実行されている間、そのカードは **予定** から **実行中** へ移動し（実行中に起動された子バックグラウンドジョブやワークフローの状態も集約します）、正常に完了すると **前回実行** と **次回実行** を更新して再び **予定** カラムへ戻ります。

### 各カラムの内容

- **予定**：Worker スロットを待っている単発 Agent ジョブ、待機中または **一時停止中** の Cron スケジュール、正常待機中のページ自動化、実行時刻前の **後で確認** タイマー。
- **実行中**：現在動いている実行と、確認・対応が必要なすべての項目。Pod は対応が必要なカード——**入力待ち**（`waiting_on_user`）の Agent ジョブ、過去 48 時間以内に失敗したジョブ・ワークフロー・Cron 実行、権限や資格情報の変更で **利用不可** になったページ自動化——を **実行中** カラムの先頭に固定表示し、その下に通常の稼働中アイテムを並べます。
- **完了**：終了した単発の Agent ジョブとワークフロー（直近 120 件まで表示）。

Agent ごとの稼働状況を確認したいときは、**ボード表示** を **Agent 別** に切り替えると、各 Agent（および **ページ自動化** グループ）単位で実行中・予定・完了の作業をまとめて確認できます。

## 単発ジョブや定期 Cron を作成する

普段の **チャット** でパーソナルアシスタントや AI 同僚にバックグラウンド作業や定期実行を依頼すれば、その会話から開始されたバックグラウンド Agent ジョブ、ワークフロー、Cron スケジュール、後で確認タイマーは自動的に **Jobs** ボードへ反映されます。

チャットを開かずにボードから直接ジョブを投入する場合は、右上の **新規ジョブ** を選択します（ボードが空のときはスターターテンプレートから始めることもできます）。

1. **単発ジョブ**：バックグラウンド実行に対応した **Agent** を選び、**タイトル** と **指示内容** を入力して **結果の通知先** を指定します。
   - **Jobs ボードのみ（チャットルームを作成しない）** を選ぶと、Agent の Worker 上で独立したバックグラウンドジョブ（`pod_job:<request_id>`）として実行され、**チャット** に新しいルームを作らず **Jobs** ボード内だけで完結します。
   - 既存の会話ルームを選ぶと、実行がそのルームに紐づけられ、完了時に結果の要約がチャットへ投稿されます。
2. **定期 Cron**：**Agent** を選び、**タイトル** と **指示内容** を入力したうえで、プリセット（**平日 09:00** など）または **カスタム Cron 式**（5 フィールド）と **タイムゾーン**、通知先ルーム（または **Agent のダイレクトチャット**）を指定します。**対応が必要なときだけ通知する** をオンにしておくと、問題のない定常実行はチャットを鳴らさず静かに完了し、異常の検知や判断が必要なときだけ通知が届きます。作成と同時に 1 回目を走らせたい場合は **作成後すぐに初回を実行する** をオンにします。

### API からの操作

Pod メンバーとして認証されたスクリプトやツールからは、`/api/v2/pod/jobs` エンドポイントを通じてボードの参照と操作を行えます（リクエストボディは JSON:API アクション形式 `{"data": ...}` を使用します）。

| メソッド | パス | 用途 |
| --- | --- | --- |
| `GET` | `/api/v2/pod/jobs/summary` | `scheduledCount`、`runningCount`、`attentionCount` の件数サマリーを取得 |
| `GET` | `/api/v2/pod/jobs` | 表示可能なボードの `items` と呼び出し可能な `agents` を一覧取得 |
| `POST` | `/api/v2/pod/jobs` | `one_off` ジョブまたは `cron` スケジュールを作成（`mode`、`agentUID`、`title`、`task`、`requestID`、および任意の `conversationID`、`repeat`、`quietSuccess`、`runNow`） |
| `GET` | `/api/v2/pod/jobs/routines/:kind/:raw_id` | `cron`・`automation_job`・`checkback` カードの指示内容、委任された子実行、実行履歴を取得 |
| `PATCH` | `/api/v2/pod/jobs/routines/:kind/:raw_id` | 自分が作成したルーチンを操作（`cron` は `pause`・`resume`・`run`・`remove`、`checkback` は `cancel`） |
| `GET` | `/api/v2/pod/jobs/executions/:kind/:run_id` | `background_agent_job` または `workflow` の計画、ツール実行ステップ、出力ログを取得 |
| `POST` | `/api/v2/pod/jobs/executions/:kind/:run_id/stop` | 待機中または実行中の `background_agent_job` / `workflow` を停止 |
| `POST` | `/api/v2/pod/jobs/executions/background_agent_job/:run_id/messages` | 質問への回答、実行中の軌道修正、または完了済みジョブの継続実行を送信（`requestID`、`text`） |

## 詳細の確認・指示の送信・スケジュールの制御

カードを選択すると、ボードの右側にインスペクターパネルが開きます（同じ会話やページへのアクセス権を持つメンバーには、`/jobs?item=<id>` のリンクをそのまま共有できます）。

- **Agent ジョブとワークフロー**：Agent の計画、各ステップのツール呼び出し、出力サマリーをリアルタイムに表示します。バックグラウンド Agent ジョブが **入力待ち** のとき、実行中のとき、あるいはワークスペースセッションを残して完了したときは、パネル下部の入力欄からそのまま回答や追加指示を送って作業を継続でき、稼働中であれば **停止** でキャンセルできます。会話ルームに紐づく実行では **チャットで開く** から元の会話へ移動できます。
- **Cron・後で確認・ページ自動化**：**次回実行**、**前回実行**、登録された **指示内容**、**委任された実行**（クリックすると各子ジョブのステップ詳細を開けます）、および **実行履歴** を表示します。自分の権限で作成した Cron スケジュールや後で確認タイマーは、ヘッダーの **今すぐ実行**・**一時停止**・**再開**・**削除**・**キャンセル** から直接操作でき、ページ自動化では **Applet を開く** から対象のページを開けます。

## 表示範囲と権限

各メンバーの **Jobs** ボードには、Pod 内で自分がアクセス権を持つ項目だけが表示されます。

- **Jobs ボードのみ** で起動した単発ジョブは、作成した本人にのみ表示されます。
- **チャット** リストの会話に紐づくジョブ、ワークフロー、Cron スケジュール、後で確認タイマーは、その会話の参加メンバーに表示されます（ページのコメントスレッド内の実行は各ページ側に留まり、**Jobs** ボードには並びません）。Cron スケジュールや後で確認タイマーの一時停止・再開・即時実行・削除を行えるのは、そのスケジュールを作成したメンバー本人のみです。
- **ページ自動化** には閲覧権限のあるページ上の有効な Applet 自動化ジョブが表示されます。他のメンバー個人の権限（`human` 認可）で動く Applet 自動化は、その所有者本人にのみ表示されます。
