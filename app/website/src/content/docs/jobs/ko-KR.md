Pod에서 **채팅**(Chat)이 사람 및 Agent와 실시간으로 대화를 나누는 공간이라면, **Jobs**(`/jobs`)는 워크스페이스 안의 모든 비동기 실행과 상시 일정을 한 보드에 모아 보여 주는 관리 화면입니다. 일회성 백그라운드 Agent 잡과 다단계 워크플로부터 반복 실행되는 Cron 일정, 나중에 확인 타이머, 페이지에 속한 Applet 자동화 잡까지 다음에 예정된 작업, 지금 실행 중이거나 확인이 필요한 작업, 완료된 작업 흐름으로 한눈에 파악할 수 있습니다.

## 보드 열기

Pod 왼쪽 사이드바의 **홈** 탭에서 **공유 문서함** 바로 위에 있는 **Jobs**를 선택하거나, `⌘K`(Windows·Linux에서는 `Ctrl+K`)를 눌러 명령 메뉴에서 **Jobs**로 바로 이동합니다.

진행 중인 백그라운드 작업이 있을 때는 사이드바의 **Jobs** 항목 옆에 실시간 배지가 표시됩니다.

- **실행 중** 열에 질문 응답 대기나 최근 실행 실패처럼 직접 확인해야 할 항목이 있으면 주황색 배지로 건수를 알려 줍니다.
- 별도 개입이 필요한 항목 없이 작업이 정상 진행 중일 때는 현재 실행 중인 건수를 안내 배지로 표시합니다.

보드 상단 헤더에서는 지금 일하고 있는 Agent를 바로 확인할 수 있으며, **보드 보기**를 **상태별**과 **Agent별** 사이에서 전환하거나 **필터** 메뉴로 담당 Agent(또는 **페이지 자동화**)와 항목 **유형**을 골라 볼 수 있습니다.

## 일회성 잡과 상시 루틴 카드

보드는 **예정됨**, **실행 중**, **완료됨** 세 열에 걸쳐 성격이 다른 두 가지 카드를 함께 다룹니다.

- **일회성 잡**(**Agent 잡** 및 **워크플로**)은 시작 후 실행을 마치고 나면 **완료됨** 열로 이동합니다. 끝난 백그라운드 Agent 잡에 추가 지시를 보내 후속 실행으로 이어 가면, Ankole이 전체 연속 실행 체인을 카드 한 장으로 묶어 보여 주므로 처음부터 끝까지 하나의 작업 흐름으로 추적할 수 있습니다.
- **상시 루틴**(**Cron**, **자동화**, **나중에 확인**)은 반복 일정, Applet 트리거, 예약된 확인 알림을 나타냅니다. 실행될 때마다 새 카드가 늘어나는 대신 규칙 하나가 항상 고유한 카드 한 장에 대응합니다. Cron 일정이나 페이지 자동화가 실행되는 동안에는 해당 카드가 **예정됨**에서 **실행 중**으로 옮겨 가며(해당 회차에서 위임 실행된 하위 백그라운드 Agent 잡과 워크플로 상태도 함께 집계합니다), 문제없이 실행을 마치면 **최근 실행**과 **다음 실행** 시각을 갱신한 뒤 다시 **예정됨** 열로 돌아옵니다.

### 열별 표시 기준

- **예정됨**: Worker 슬롯을 기다리는 일회성 Agent 잡, 대기 중이거나 **일시 중지됨** 상태인 Cron 일정, 정상 대기 중인 페이지 자동화, 아직 시각이 되지 않은 **나중에 확인** 타이머가 놓입니다.
- **실행 중**: 현재 돌아가고 있는 실행과 사용자의 확인이 필요한 모든 항목이 표시됩니다. Pod는 **입력 대기**(`waiting_on_user`) 상태인 Agent 잡, 최근 48시간 이내에 실패한 잡·워크플로·Cron 실행, 권한이나 자격 증명 문제로 **사용 불가** 상태가 된 페이지 자동화처럼 확인이 필요한 카드를 **실행 중** 열 맨 위에 고정하고, 그 아래에 정상 실행 중인 작업을 나란히 배치합니다.
- **완료됨**: 종료된 일회성 Agent 잡과 워크플로를 최근 120건까지 보관해 보여 줍니다.

담당 주체별로 작업 현황을 살펴보고 싶다면 **보드 보기**를 **Agent별**로 전환해 각 Agent(및 별도의 **페이지 자동화** 그룹) 아래에서 실행 중·예정됨·완료됨 항목을 모아 볼 수 있습니다.

## 새 잡 또는 반복 Cron 일정 만들기

평소처럼 **채팅**에서 개인 비서나 AI 동료에게 백그라운드 작업을 맡기거나 반복 일정을 요청하면, 대화방에서 시작된 백그라운드 Agent 잡, 워크플로, Cron 일정, 나중에 확인 타이머가 별도 조작 없이도 **Jobs** 보드에 자동으로 나타납니다.

채팅방을 거치지 않고 보드에서 곧바로 작업을 지시하려면 오른쪽 위의 **새 잡**을 선택합니다(보드가 비어 있을 때는 시작 템플릿을 골라 바로 채울 수도 있습니다).

1. **일회성 잡**: 백그라운드 실행이 가능한 **Agent**를 고르고 **제목**과 **지시 사항**을 입력한 뒤 **결과 전달 위치**를 선택합니다.
   - **Jobs 보드에서만 확인 (대화방 생성 안 함)**을 선택하면 선택한 Agent의 Worker에서 독립 실행(`pod_job:<request_id>`)되며, **채팅** 목록에 새 대화방을 만들지 않고 **Jobs** 보드 안에서만 진행 과정과 결과를 확인합니다.
   - 기존 대화방을 선택하면 실행이 해당 방에 연결되어 완료 시 결과 요약이 대화방으로 함께 전달됩니다.
2. **반복 Cron**: **Agent**를 고르고 **제목**과 **지시 사항**을 작성한 다음, 기본 일정 프리셋(**평일 오전 9:00** 등)을 고르거나 **사용자 지정 Cron 표현식**(5필드)과 **시간대**를 입력하고 결과 전달 대화방(또는 **Agent 1:1 대화방**)을 지정합니다. **확인이 필요할 때만 알림 보내기**를 켜 두면 이상 없이 끝난 정기 실행은 채팅 알림을 울리지 않고 조용히 마무리되며, 이상 징후가 감지되거나 의사결정이 필요할 때만 대화방으로 알려 줍니다. 일정을 등록하자마자 첫 회차를 곧바로 실행하려면 **생성 직후 첫 실행 시작**을 함께 선택합니다.

### API로 제어하기

Pod 멤버 권한으로 인증된 스크립트나 외부 도구는 `/api/v2/pod/jobs` 엔드포인트를 통해 보드를 조회하고 제어할 수 있습니다(요청 본문은 JSON:API 액션 형식인 `{"data": ...}`로 전달합니다).

| 메서드 | 경로 | 용도 |
| --- | --- | --- |
| `GET` | `/api/v2/pod/jobs/summary` | `scheduledCount`, `runningCount`, `attentionCount` 요약 건수 조회 |
| `GET` | `/api/v2/pod/jobs` | 조회 가능한 보드 `items` 및 호출 가능한 `agents` 목록 조회 |
| `POST` | `/api/v2/pod/jobs` | `one_off` 잡 또는 `cron` 일정 생성 (`mode`, `agentUID`, `title`, `task`, `requestID`, 선택 항목 `conversationID`, `repeat`, `quietSuccess`, `runNow`) |
| `GET` | `/api/v2/pod/jobs/routines/:kind/:raw_id` | `cron`, `automation_job`, `checkback` 카드의 지시 사항, 위임된 하위 실행, 실행 기록 조회 |
| `PATCH` | `/api/v2/pod/jobs/routines/:kind/:raw_id` | 본인이 만든 루틴 제어 (`cron`은 `pause`, `resume`, `run`, `remove`, `checkback`은 `cancel`) |
| `GET` | `/api/v2/pod/jobs/executions/:kind/:run_id` | `background_agent_job` 또는 `workflow`의 실시간 계획, 도구 실행 단계, 출력 로그 조회 |
| `POST` | `/api/v2/pod/jobs/executions/:kind/:run_id/stop` | 대기 중이거나 실행 중인 `background_agent_job` / `workflow` 중지 |
| `POST` | `/api/v2/pod/jobs/executions/background_agent_job/:run_id/messages` | 질문에 답변하거나 실행 중인 잡의 방향을 조정하고 완료된 잡을 이어서 실행 (`requestID`, `text`) |

## 상세 확인, 추가 지시 및 실행 제어

아무 카드나 선택하면 보드 오른쪽에 상세 인스펙터 패널이 열립니다(같은 대화방이나 페이지 접근 권한이 있는 동료에게는 `/jobs?item=<id>` 링크를 그대로 공유할 수 있습니다).

- **Agent 잡 및 워크플로**: Agent가 세운 계획, 단계별 도구 호출 내역, 결과 요약을 실시간으로 보여 줍니다. 백그라운드 Agent 잡이 **입력 대기** 상태이거나 실행 중일 때, 또는 워크스페이스 세션을 유지한 채 완료되었을 때는 패널 하단 입력창에서 바로 답변이나 후속 지시를 보내 작업을 이어 갈 수 있으며, 실행 중인 작업은 **중지** 버튼으로 즉시 멈출 수 있습니다. 대화방에 연결된 실행이라면 **채팅에서 열기**를 눌러 원래 대화방으로 바로 이동합니다.
- **Cron, 나중에 확인 및 페이지 자동화**: **다음 실행**, **최근 실행**, 등록된 **지시 사항**, **위임된 실행**(항목을 클릭하면 하위 실행의 전체 단계 로그로 바로 들어갑니다), **실행 기록**을 확인할 수 있습니다. 내 권한으로 생성한 Cron 일정과 나중에 확인 타이머는 패널 상단에서 **지금 실행**, **일시 중지**, **다시 시작**, **삭제**, **취소**를 바로 실행할 수 있으며, 페이지 자동화는 **Applet 열기**를 눌러 해당 페이지로 이동합니다.

## 공개 범위와 권한

각 멤버의 **Jobs** 보드는 Pod 안에서 본인이 접근할 수 있는 범위만 정확히 반영합니다.

- **Jobs 보드에서만 확인**으로 시작한 독립 일회성 잡은 작업을 시작한 본인에게만 보입니다.
- **채팅** 목록의 대화방에 연결된 잡, 워크플로, Cron 일정, 나중에 확인 타이머는 해당 대화방 참여 멤버들에게 표시됩니다(페이지 댓글 스레드에서 실행된 작업은 각 페이지 안에 머물며 **Jobs** 보드에는 나타나지 않습니다). Cron 일정이나 나중에 확인 타이머를 일시 중지, 다시 시작, 즉시 실행, 삭제할 수 있는 권한은 해당 일정을 만든 작성자에게만 부여됩니다.
- **페이지 자동화**에는 열람 권한이 있는 페이지의 활성 Applet 자동화 잡이 표시되며, 다른 멤버 개인 권한(`human` 인가 방식)으로 동작하는 Applet 자동화는 그 소유자에게만 보입니다.
