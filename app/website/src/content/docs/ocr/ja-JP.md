ファイルを Agent に送り、抽出したいテキストを伝えるだけで利用できます。Agent Computer Worker に OCR 機能が標準で組み込まれているため、別途モデル Provider や API キー、外部の OCR サービスを設定する必要はありません。

たとえば、次のように依頼できます。

```text
Read all text in this screenshot and keep the original reading order.

Extract pages 2 to 5 from this scanned PDF. Mark any text that you cannot read with confidence.

Read this receipt and list the merchant, date, items, tax, and total.
```

## 一般的な CPU で動く高度な認識

Ankole は、CPU 環境向けに最適化された高精度な検出・認識モデルである [PaddleOCR PP-OCRv6 medium](https://www.paddleocr.ai/latest/en/version3.x/algorithm/PP-OCRv6/PP-OCRv6.html) を採用しています。`medium` は PP-OCRv6 ファミリーの中で認識精度を重視したモデルであり、PaddleOCR の評価では PP-OCRv5_server と比較してテキスト検出（text detection）が 4.6%、テキスト認識（text recognition）が 5.1% 向上しています。

単一のモデルで 50 言語（簡体字中国語、繁体字中国語、英語、日本語、および 46 のラテン文字系言語）に対応しており、スキャン文書だけでなく、スクリーンショット、看板、商品ラベル、デジタル表示器など実世界の多様な画像内テキストを読み取れます。

推論は OpenVINO で最適化された CPU 実行パスを通じてローカルで行われるため、GPU を持たない標準的な Worker でも高速に動作します。モデル自体はあらかじめ Worker イメージに同梱されており、文書データが外部の OCR サービスへ送信されることはなく、ページ単位の従量課金も発生しません。

## Ankole が精度の高い手順を選ぶ

OCR は画像のピクセルから文字を推定する仕組みですが、デジタル文書から直接テキストを取り出せる場合は元の文字情報をそのまま正確に取得できます。そのため Ankole は、ファイルの状態に応じてより精度の高い方法を優先して使います。

- **テキストレイヤーを持つ PDF：** 元のテキストデータを直接抽出します。
- **全面スキャンの PDF：** 全ページに対して OCR を実行します。
- **テキストとスキャンが混在する PDF：** 画像化されたページにだけ OCR を使い、残りのページはテキストを直接抽出します。
- **DOCX・PPTX・XLSX ファイル：** ページを画像化するのではなく、オフィス文書の内部構造を直接読み取ります。

ユーザー側で処理方式を指定する必要はありません。手元に元データがある場合はそのまま添付し、どのような形式で結果が欲しいかを伝えてください。

## Agent が返せるもの

読み取った内容をもとに、プレーンテキスト、整形済みの文字起こし、要約、あるいは構造化された項目リストなどを返せます。OCR エンジンからは各行の位置座標と確信度（confidence）も出力されるため、Agent は元の読み順を保ちつつ、スキャン品質の低下などで判読が不確かな箇所があればユーザーに警告できます。

認識精度を高めるには、ピントが合っていて向きが正しく、解像度が十分な画像を用意してください。細かい文字が含まれる場合は、圧縮されたスクリーンショットではなく元のファイルを渡すのが効果的です。また、「判読に自信がない行は推測で補わず、その旨を明記してください」と指示しておくこともできます。

## 制限

- 韓国語、アラビア語、キリル文字、タイ語など、50 言語モデルの対象外となる文字体系には対応していません。
- 手書き文字、数式、複雑な表組み、湾曲したテキスト、ピンぼけや大きく傾いた写真では、認識精度が低下する場合があります。また、表は座標付きのテキスト行として抽出されるため、元のセル構造がそのまま維持されるとは限りません。
- OCR は文面を読み取るための機能であり、元の PDF ファイル自体に検索可能な透明テキストレイヤーを埋め込む処理は行いません。

`ocr` Skill はデフォルトで有効になっています。もし Agent から「OCR を利用できない」と返答された場合は、最新の Worker イメージで稼働しているか、および **Agent Library** で `ocr` Skill が有効になっているかを確認してください。
