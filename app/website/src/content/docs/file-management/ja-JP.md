**ほとんどの場合、このページで説明するファイルブラウザは必要ありません。ファイルを Agent に送るか、チャットで作成、読み取り、変更、整理、送信を依頼してください。配信されなかった成果物を取り戻す場合、途中ファイルを調べる場合、または手動でファイルを整理する場合にだけ Console を使います。**

Agent は参照資料を読み取り、作業と成果物を Worker の永続ストレージに保存します。Console では、参照資料のアップロード、report や画像、データファイルのダウンロード、不要になった資料の名前変更や削除ができます。

## Agent のファイルを見つける

1. Console で **Workers** を開きます。
2. 利用可能な Worker を選択し、**Browse files** を選択します。
3. Agent を選択します。
4. ファイルルートを選択します。

| ルート | 内容 | よくある操作 |
|---|---|---|
| **ユーザーファイル** | 人が提供した参照資料、テンプレート、入力ファイル | アップロード、ダウンロード、名前変更、削除 |
| **Agent セッション** | Agent の会話から生まれた作業ファイル | 成果物のダウンロード、不要になった古いファイルの削除 |
| **Agent インストール済み Skill** | Agent が現在読み取れる Skill ファイル | 同期の確認。通常はここで編集しない |

リストは 1 つの Worker 経由で開きますが、本番デプロイのすべての Worker は Agent の永続ストレージを共有する必要があります。Docker Compose はローカルの永続ボリュームを使い、Kubernetes は複数ノードが読み書きできる共有ボリュームを使います。

Worker ごとに異なるファイルが表示される場合は、重複をアップロードするのではなく、ストレージのマウントを修復してください。

## 参照資料をアップロードする

1. **ユーザーファイル**を開きます。
2. 対象ディレクトリを開くか、アップロード時にサブディレクトリを指定します。
3. **Upload** を選択してファイルを追加します。
4. チャットで、Agent にファイル名、ディレクトリ、タスクを伝えます。

アップロードすると、存在しないサブディレクトリが自動的に作成されます。`customer-research/2026-q3-interviews.pdf` のような安定した名前を使ってください。すべてのファイルをルートに置かず、`final-v2-new.pdf` のように内容を特定できない名前は避けてください。

アップロードによってファイルが読み取り可能になります。作業は開始されません。チャットで Agent に使うよう伝えてください。資料を長期的な知識に変えるには、**Learn source** から送信します。

## Agent の成果物をダウンロードする

Agent が会話中にファイルを作成したら、**Agent セッション** で見つけてダウンロードします。ディレクトリが大きい場合は、まず該当する会話パスを開き、名前または種類で検索します。

添付ファイルがチャットに届いている場合は、そこでダウンロードします。Console は、配信されなかった成果物の回収、途中ファイルの確認、保持が必要な結果の整理に使います。

## 名前の変更と削除

ファイルのアクションメニューから、名前の変更または削除ができます。名前の変更はファイルの内容を変更しません。

削除は恒久的で、ゴミ箱はありません。ディレクトリを削除すると、その子要素も削除されます。稼働中の Agent の作業がそのファイルを使っていないことを確認してください。

重要な資料は先にダウンロードするか、[バックアップ](../backup-and-restore/) に含まれていることを確認してください。

**Agent インストール済み Skill** のファイルは編集しないでください。Skill の有効化は [Agent Library](../skills/) で管理します。Skill の内容はそのソースで変更し、再度同期してください。

## 再起動後も残るもの

ユーザーファイル、Agent セッションファイル、インストール済み Skill は永続ストレージにあり、Worker の再起動後も残ります。Worker の一時ディレクトリはこのビューの外にあり、再起動後に消えることがあります。

Agent の `MISSION`、`SOUL`、`DESIGN` ドキュメントは Agent エディタで管理されます。これらは Worker に投影されますが、ファイルブラウザから変更してはいけません。これらのドキュメントについては [Agents](../agents/) を参照してください。

## よくある問題

- **リストが空の場合:** Worker、Agent、ファイルルートを確認し、Worker が利用可能であることを確認します。
- **Agent がアップロードしたファイルを見つけられない場合:** そのファイルが該当 Agent の **ユーザーファイル** にあることを確認し、メッセージに正確な相対パスを含めます。
- **一部の Worker にしかファイルが表示されない場合:** すべての Worker が同じ永続ボリュームをマウントしていることを確認します。
- **生成された成果物がない場合:** Job が完了したことを確認し、正しい会話ディレクトリを調べます。
- **リストが切り詰められている場合:** より具体的なサブディレクトリを開いて再度検索します。
