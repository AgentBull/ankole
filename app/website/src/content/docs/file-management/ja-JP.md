**通常、このページで説明するファイルブラウザは必要ありません。チャットで Agent に直接ファイルを送信して、ファイルの作成、読み取り、変更、整理、転送を行ってください。配信されなかった成果物の復旧、保存済みの出力の確認、または手動でのフォルダ整理が必要な場合にのみ、Console のファイルブラウザを使用します。**

各 Agent の control plane ドライブは添付ファイル、画像、公開ファイル、Skill、Automation スクリプトを保存します。Worker が停止中でも Console から操作できます。Session と Job workspace は永続 Home にあり、ドライブ内のフォルダーではありません。

## Agent のファイルを探す

1. Console で **Agents** を開き、対象の Agent を開きます。
2. **ドライブ**で**ファイルを閲覧**を選択します。

| フォルダ | 内容 |
|---|---|
| `inbox/` | Agent に送られた添付ファイル |
| `generated/` | Agent が生成した画像 |
| `sent/` | Agent が返信に添付したファイル |
| `skills/` | Agent のインストール済み Skill（Skill ごとに 1 フォルダ） |
| `automation/` | Automation Job のスクリプト |
| その他のフォルダ | Agent または利用者が保存したファイル |

## 参照資料をアップロードする

1. 対象のフォルダを開くか、アップロード時にフォルダを入力します。
2. **アップロード**を選択してファイルを追加します。同じパスにあるファイルは置き換えられます。
3. チャットで、ドライブのパスとタスクを Agent に伝えます。

パス中のフォルダはアップロード時に作成されます。`customer-research/2026-q3-interviews.pdf` のような安定した名前を使ってください。すべてのファイルをルートに置かず、`final-v2-new.pdf` のように内容がわからない名前は避けてください。

アップロードすると Agent がファイルを取得できるようになりますが、作業は始まりません。チャットで Agent に使うよう伝えてください。資料を永続的な知識にするには **Learn source** から送信します。

## Agent の成果物をダウンロードする

ドライブには、Agent が保存したファイルと返信に添付したファイル（`sent/` 配下）があります。Agent が会話ワークスペースに書いただけのファイルはドライブにありません。Agent に保存を依頼してください。

添付ファイルがチャットで届いている場合は、そこでダウンロードしてください。Console は、配信されなかった成果物の復旧、保存済みの出力の確認、保持すべき結果の整理に使います。

## 移動と削除

ファイルやフォルダの操作メニューから、移動、名前の変更、削除ができます。移動してもファイルの内容は変わりません。

削除は元に戻せず、ゴミ箱はありません。フォルダを削除すると、その中のすべてのファイルが削除されます。進行中の Agent の作業がそのファイルを使っていないことを確認してください。

重要な資料は先にダウンロードするか、[バックアップ](../backup-and-restore/) に含まれていることを確認してください。

`skills/` 配下のファイルはインストール済みの Skill そのものです。変更すると次のターンからその Skill が変わります。Skill の有効化は [Agent Library](../skills/) で管理します。

## 再起動後に残るもの

ドライブと永続 Home は Worker 置換後も残ります。workspace だけに書いたファイルは Home にあり、Console で取得するにはドライブに公開します。制限は [Worker](../worker-management/) を参照してください。

Agent の `MISSION`、`SOUL`、`DESIGN` ドキュメントは Agent エディタで管理します。これらは Worker に投影されますが、ドライブのファイルではありません。これらのドキュメントについては [Agents](../agents/) を参照してください。

## よくある問題

- **Agent がアップロードしたファイルを見つけられない：** メッセージに正確なドライブのパスを書いてください。Agent は `ankole-files get` で取得します。
- **生成した成果物が見当たらない：** Agent にドライブへの保存を依頼するか、Job が完了したことを確認してください。
- **サイズのエラーでアップロードに失敗する：** 1 ファイルの上限は 100 MiB です。
- **添付ファイルが利用不可と表示される：** ドライブ導入前に届いたか、ダウンロードに失敗しています。送信者に再送を依頼してください。
