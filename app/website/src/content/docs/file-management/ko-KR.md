**일반적으로 이 페이지에서 설명하는 파일 브라우저는 필요하지 않습니다. 채팅에서 Agent에게 직접 파일을 보내 생성, 읽기, 수정, 정리 또는 전송하세요. 전달되지 않은 산출물을 복구하거나 저장된 출력을 확인하거나 수동으로 폴더를 정리해야 할 때만 Console 파일 브라우저를 사용하세요.**

각 Agent의 control plane 드라이브에는 첨부 파일, 이미지, 게시한 파일, Skill, Automation 스크립트가 있습니다. Worker가 없어도 Console에서 관리할 수 있습니다. Session과 Job 작업 공간은 영구 Home에 있으며 드라이브 폴더가 아닙니다.

## Agent의 파일 찾기

1. Console에서 **Agents**를 열고 해당 Agent를 엽니다.
2. **드라이브**에서 **파일 탐색**을 선택합니다.

| 폴더 | 내용 |
|---|---|
| `inbox/` | 사람들이 Agent에게 보낸 첨부 파일 |
| `generated/` | Agent가 생성한 이미지 |
| `sent/` | Agent가 답장에 첨부한 파일 |
| `skills/` | Agent에 설치된 Skill(Skill마다 폴더 하나) |
| `automation/` | Automation Job 스크립트 |
| 그 밖의 폴더 | Agent나 사람이 저장한 파일 |

## 참고 자료 업로드

1. 대상 폴더를 열거나 업로드할 때 폴더를 입력합니다.
2. **업로드**를 선택하고 파일을 추가합니다. 같은 경로에 있는 파일은 대체됩니다.
3. 채팅에서 Agent에게 드라이브 경로와 작업을 알려 줍니다.

경로의 폴더는 업로드할 때 만들어집니다. `customer-research/2026-q3-interviews.pdf`처럼 안정적인 이름을 사용하세요. 모든 파일을 루트에 두지 말고, `final-v2-new.pdf`처럼 내용을 알 수 없는 이름은 피하세요.

업로드하면 Agent가 파일을 가져올 수 있게 되지만 작업이 시작되지는 않습니다. 채팅에서 Agent에게 사용하라고 알려 주세요. 자료를 영구 지식으로 만들려면 **Learn source**로 제출합니다.

## Agent 산출물 다운로드

드라이브에는 Agent가 저장한 파일과 답장에 첨부한 파일(`sent/` 아래)이 있습니다. Agent가 대화 워크스페이스에만 쓴 파일은 드라이브에 없습니다. Agent에게 저장을 요청하세요.

첨부 파일이 채팅으로 도착했다면 채팅에서 다운로드하세요. Console은 전달되지 않은 산출물을 복구하거나, 저장된 출력을 확인하거나, 보관해야 할 결과를 정리할 때 사용합니다.

## 이동과 삭제

파일이나 폴더의 작업 메뉴에서 이동, 이름 변경, 삭제를 할 수 있습니다. 이동해도 파일 내용은 바뀌지 않습니다.

삭제는 영구적이며 휴지통이 없습니다. 폴더를 삭제하면 그 안의 모든 파일이 삭제됩니다. 진행 중인 Agent 작업이 해당 파일을 사용하지 않는지 확인하세요.

중요한 자료는 먼저 다운로드하거나 [백업](../backup-and-restore/)에 포함되어 있는지 확인하세요.

`skills/` 아래의 파일은 설치된 Skill 자체입니다. 수정하면 다음 turn부터 해당 Skill이 바뀝니다. Skill 활성화는 [Agent Library](../skills/)에서 관리합니다.

## 재시작 후 남는 것

드라이브와 영구 Home은 Worker 교체 후에도 유지됩니다. 작업 공간에만 쓴 파일은 Home에 있으며 Console에서 받으려면 드라이브에 게시해야 합니다. 제한은 [Worker](../worker-management/)를 참조하세요.

Agent의 `MISSION`, `SOUL`, `DESIGN` 문서는 Agent 편집기에서 관리합니다. 이 문서들은 Worker에 투영되지만 드라이브 파일이 아닙니다. 해당 문서는 [Agents](../agents/)를 참조하세요.

## 자주 발생하는 문제

- **Agent가 업로드한 파일을 찾지 못함:** 메시지에 정확한 드라이브 경로를 적으세요. Agent는 `ankole-files get`으로 파일을 가져옵니다.
- **생성된 산출물이 없음:** Agent에게 드라이브에 저장하라고 요청하거나 Job이 끝났는지 확인하세요.
- **크기 오류로 업로드 실패:** 파일 하나는 최대 100 MiB입니다.
- **첨부 파일이 사용할 수 없음으로 표시됨:** 드라이브가 생기기 전에 도착했거나 다운로드에 실패한 파일입니다. 보낸 사람에게 다시 보내 달라고 요청하세요.
