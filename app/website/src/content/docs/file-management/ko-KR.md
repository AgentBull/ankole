**대부분의 경우 이 페이지에서 설명하는 파일 브라우저는 필요하지 않습니다. 파일을 Agent에게 보내거나, 채팅에서 파일 생성·읽기·변경·정리·보내기를 요청하세요. 전달되지 않은 산출물을 복구하거나, 중간 파일을 검사하거나, 파일을 수동으로 정리해야 할 때만 Console을 사용하세요.**

Agent는 원본 자료를 읽고, 작업과 산출물을 지속적인 Worker 스토리지에 저장합니다. Console을 사용하면 참고 자료를 업로드하고, 보고서·이미지·데이터 파일을 다운로드하며, 더 이상 필요 없는 자료를 이름 변경하거나 제거할 수 있습니다.

## Agent의 파일 찾기

1. Console에서 **Workers**를 엽니다.
2. 사용 가능한(ready) Worker를 선택한 다음 **Browse files**를 선택합니다.
3. Agent를 선택합니다.
4. 파일 루트를 선택합니다:

| 루트 | 내용 | 일반적인 작업 |
|---|---|---|
| **사용자 파일** | 사람이 제공한 참고 자료, 템플릿, 입력 파일 | 업로드, 다운로드, 이름 변경 또는 제거 |
| **Agent 세션** | Agent 대화의 작업 파일 | 산출물 다운로드, 필요시 오래된 파일 제거 |
| **Agent 설치 Skill** | Agent가 현재 읽을 수 있는 Skill 파일 | 동기화 확인; 일반적으로 여기서 편집하지 않음 |

목록은 하나의 Worker를 통해 열리지만, 프로덕션 배포의 모든 Worker는 지속적인 Agent 스토리지를 공유해야 합니다. Docker Compose는 로컬 영구 볼륨을 사용합니다. Kubernetes는 여러 노드가 읽고 쓸 수 있는 공유 볼륨을 사용합니다.

Worker마다 다른 파일이 보이면 중복 사본을 업로드하는 대신 스토리지 마운트를 수리하세요.

## 참고 자료 업로드

1. **사용자 파일**를 엽니다.
2. 대상 디렉터리를 열거나, 업로드 중에 하위 디렉터리를 입력합니다.
3. **Upload**를 선택하고 파일을 추가합니다.
4. 채팅에서 Agent에게 파일 이름, 디렉터리, 작업을 알려 줍니다.

업로드하면 누락된 하위 디렉터리가 생성됩니다. `customer-research/2026-q3-interviews.pdf`처럼 안정적인 이름을 사용하세요. 모든 파일을 루트에 두지 말고, 내용을 식별할 수 없는 `final-v2-new.pdf` 같은 이름은 피하세요.

업로드는 파일을 읽을 수 있게 만들 뿐입니다. 작업이 시작되지는 않습니다. 채팅에서 Agent에게 사용하라고 알려 주세요. 자료를 지속적인 지식으로 만들려면 **Learn source**를 통해 제출하세요.

## Agent 산출물 다운로드

Agent가 대화에서 파일을 만든 후에는 **Agent 세션**에서 찾아 다운로드하세요. 큰 디렉터리의 경우 먼저 관련 대화 경로를 연 다음 이름이나 종류로 검색하세요.

첨부 파일이 채팅으로 도착했다면 그곳에서 다운로드하세요. 전달되지 않은 산출물을 복구하거나, 중간 파일을 검사하거나, 보존해야 하는 결과를 정리할 때는 Console을 사용하세요.

## 이름 변경 및 제거

파일의 작업 메뉴에서 이름 변경 또는 제거를 사용하세요. 이름을 변경해도 파일 내용은 바뀌지 않습니다.

제거는 영구적이며 휴지통이 없습니다. 디렉터리를 제거하면 하위 항목도 제거됩니다. 활성 Agent 작업이 그 파일들을 사용하지 않는지 확인하세요.

중요한 자료는 먼저 다운로드하거나 [백업](../backup-and-restore/)에 포함되어 있는지 확인하세요.

**Agent 설치 Skill** 아래의 파일은 편집하지 마세요. Skill 활성화는 [Agent Library](../skills/)에서 관리하세요. Skill 내용은 원본에서 변경한 후 다시 동기화하세요.

## 재시작 후에도 남는 것

User files, Agent 세션 파일, 설치된 Skill은 영구 스토리지에 저장되며 Worker 재시작 후에도 남습니다. Worker 임시 디렉터리는 이 보기밖에 있으며 재시작 후 사라질 수 있습니다.

Agent의 `MISSION`, `SOUL`, `DESIGN` 문서는 Agent 편집기에서 관리됩니다. 이 문서들은 Worker에 투영되지만 파일 브라우저로 변경해서는 안 됩니다. 해당 문서는 [Agents](../agents/)를 참조하세요.

## 흔한 문제

- **목록이 비어 있음:** Worker, Agent, 파일 루트를 확인하고 Worker가 ready 상태인지 확인하세요.
- **Agent가 업로드된 파일을 찾지 못함:** 파일이 해당 Agent의 **사용자 파일**에 있는지 확인하고, 메시지에 정확한 상대 경로를 포함하세요.
- **일부 Worker만 파일을 표시함:** 모든 Worker가 같은 영구 볼륨을 마운트하는지 확인하세요.
- **생성된 산출물이 없음:** Job이 완료되었는지 확인하고 올바른 대화 디렉터리를 검사하세요.
- **목록이 잘림:** 더 구체적인 하위 디렉터리를 열고 다시 검색하세요.
