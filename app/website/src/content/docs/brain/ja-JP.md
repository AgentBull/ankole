Brain は 1 つの説明責任を持つ principal の長期記憶です。同時に 3 つのものを保持します: agent が作業のもとにするキュレーション済み knowledge、ソースチャットで実際に言われたことに戻る想起パス、そして生の履歴をインデックス付きエピソードと提案 knowledge に変える dreaming プロセスです。人間が提案を事実にする前にレビューします。このページはそのモデルを `Ankole.Brain` の実コードにマッピングします。

決定的な性質を先に述べます: 構造化 knowledge が永続的な真実であり、Markdown はそのプロジェクションです。逆ではありません。Brain は evidence、キュレーション、現在の knowledge、人間によるレビューを調整します。チャットの evidence を所有するのは SignalsGateway のままです。Brain は保持ソースバイト、キュレーション済み knowledge、dreaming 状態、復旧記録を所有します。

## スコープ: 誰が何を見られるか

すべての Brain 読み書きは `Brain.Scope` を通ります。そのスコープは AIGateway 会話の宣言、具体的には `conversation.metadata["brain"]` からのみ導出されます。channel イベント、provider メタデータ、アンビエントなランタイム状態はフォールバックとして参照されません。スコープは `owner_uid`、`readable_store_keys` の集合、1 つの `writable_store_key`、`current_channel` を運びます。principal をまたぐ knowledge のための特別な共有オーナー `brain-shared` が存在します。

このルーティングの選択は意図的です。権限境界を操作者が見て変更できる会話宣言の上に置き、memory がたまたま最後に話した人へ流れていくのを防ぎます。

## 永続的な真実とプロジェクション

モデルは鋭い分割に基づいています:

- **構造化 knowledge** — エントリ、ブロック、リレーション、引用 — は追記専用監査付きのトランザクション操作で書かれる永続的な真実です。バッチはミューテーションと監査を一緒にコミットするか、部分的な状態を残しません。
- **Markdown プロジェクション、検索結果、注入コンテキスト** はその真実から再構築される安価なビューです。プロジェクションを失うのは不便ですが、knowledge 行を失うことは agent が信じることの変化です。

すべての読み取りは SQL でオーナーと読み取り可能ストアの述語を適用するため、スコープは呼び出し側が回避できるアプリケーションコードではなく、データベースの境界で強制されます。

## 想起: 3 つの channel、1 つの結果

agent ターンが memory を必要とするとき、想起は 2 つの evidence ソースに対して並行して実行され、結果をマージします:

- **チャット想起** は SignalsGateway がミラーした不変エントリを、会話が見える channel にスコープして読み取ります。想起されたメッセージは信頼できない履歴データとして扱い、決して指示としては扱いません。その旨の注意書きがすべての結果セットに付きます。
- **knowledge 想起** はキュレーション済み Brain エントリとブロックを読み取り、BM25 キーワード候補とベクトル候補の両方を埋め込みに対して使い、結果 token 予算内でマージして再ランキングします。
- **検索** はマージされたエントリポイントです。2 つの channel を並行して実行し、新しい evidence が優先されるよう時間的減衰を適用し、各項目の出所を示す 1 つのランク付けされたセットを返します。

エピソードはチャットと knowledge の橋渡しです。エピソードは不変のチャット層ファクトに対する時間指定可能な要約インデックスです — トピック、要約、対象とするソースエントリ ID、時間範囲、埋め込みを持ちます。明示的にナビゲーションインデックスであり、付随する注意書きはモデルに元のメッセージが権威あるものであることを伝えます。

## Dreaming: 履歴をインデックス付き memory にする

Dreaming は、モデルステップに人間を介在させずに、生のチャット履歴をエピソードと提案 knowledge に変換するオフラインプロセスです。頻度と Job が異なる 2 つのステージで実行されます。

**Stage A** は channel レベルの要約器です。未処理エントリのある channel をスキャンし、エピソード要約 Job をキューに入れます。各 Job はライトモデルプロファイルにチャットのウィンドウを要約してエピソードにするよう依頼します。channel を見られる agent に使用可能なライトプロファイルがないと、エピソードは黙ってスキップされず、利用不可として報告されます。設定で無効化された dreaming はステージをきれいに停止します。

**Stage B** は低頻度の principal レベルの knowledge キュレーションです。トランザクション外でモデル推論を実行し、検証済みの小さなオペレーション、skill オーバーレイ更新、両方のマテリアルハイウォーターマークを一緒にコミットします。そのため、部分的に適用された実行は黙ってスキップされず、再試行されます。出力は evidence 付きの提案 knowledge であり、knowledge ベースへの静かな編集ではありません。

2 ステージ分割が存在するのは、Job のコストとリスクのプロファイルが異なるからです。Stage A は安価で頻繁で、ナビゲーション補助を作ります。Stage B は高価で低頻度で、事実を提案します。分離しておくと、高価な Job が安価な Job をブロックしません。

## 書き込み権限: 誰が何を置けるか

knowledge 書き込みは明示的な `WriteAuthority` を運び、5 つのモードの 1 つを持ちます: `:human`、`:agent`、`:dreaming`、`:source_learning`、`:mechanical`。モードは書き込みが何を引用できるか、どのドキュメント ID に触れられるかを決定します。作者付きの書き込みは、オーナー、ストア、作成者を信頼されたスコープと actor から導出します。オペレーションペイロードはそれらを上書きできません。actor のない 2 つの機械的操作（`create_entry` と `delete_block`）はコンテンツを作者として書くことができず、明示的な因果的サーフェスが必要です。

こうして Brain は、dreaming とソース学習の出力が人間の決定を装うのを防ぎます。dreaming 提案は dreaming 書き込みであり、そのようにラベル付けされ、evidence が付属します。決して権威のある knowledge への静かな昇格ではありません。

## 人間による監視

モデルは監視なしで knowledge を編集することも、自分の出力を事実として提示することもありません。監視サーフェスはコンソールスコープのルートの背後にあります:

| メソッド | パス | 目的 |
|---|---|---|
| `GET` | `/brain/entries` | キュレーション済み knowledge エントリを一覧表示 |
| `GET` | `/brain/entries/:id` | 1 つのエントリを読み取る |
| `POST` | `/brain/entry-operations` | knowledge オペレーションのバッチを適用 |
| `GET` | `/brain/sources` | 保持ソースを一覧表示 |
| `POST` | `/brain/sources` | ソースを追加 |
| `POST` | `/brain/sources/:document_id/learning-runs` | ソース学習を実行 |
| `GET` | `/brain/audit-log` | 追記専用監査証跡を読み取る |
| `POST` | `/brain/audit-log/:audit_id/restorations` | 監査済みの変更を 1 つ復元 |
| `POST` | `/brain/dreaming-runs` | dreaming 実行をトリガー |
| `GET` | `/brain/dreaming-fitness` | dreaming が実行可能かを検査 |
| `GET` | `/brain/status` | Brain の健全性と設定ステータス |

監査ログは追記専用で、すべての復元自体が監査されます。したがって、agent が何を信じていたか、誰がそれを変えたかの履歴は再構築可能です。ソースの撤回は保持ソースをきれいに削除し、agent がもはや読めないバイトを引用する状態を残しません。

## Brain がそうでないもの

チャットログをくっつけたベクトルストアではありません。行が真実であり、ベクトルと Markdown はその上の便宜です。モデルが好きなものを書き込む場所でもありません — 書き込みは権限、evidence、監査を運びます。そしてチャット evidence の所有者でもありません。それは SignalsGateway に残ります。Brain の境界は、永続的でレビューされ、オーナースコープの memory と、そこに入れるべきものを提案するオフライン機構です。
