Issue は、Agent に任せるバックグラウンドの作業です。タイトルと説明、そして作業を担当する Agent が 1 つあります。Issue ごとに専用の会話があり、Agent の返信や質問、Agent が開始した Background Agent Job と Workflow が、Chat と同じ形でそこに表示されます。

## Work を開く

Pod のサイドバーで **Work** を選びます。このタブには、完了していない Issue が進み具合ごとに並びます。**ボード** を選ぶと Work ページが開き、Issue をボードまたはリストで確認できます。その下にはスケジュールされたタスクが表示されます。

Work に表示されるのは、Chat の一覧にある会話です。ページのコメントと外部チャットチャネルの会話は Work には表示されないため、そこでの実行やスケジュールはそれぞれの会話で確認してください。

ボードには 5 つの列があります。

- **未着手**：Agent はまだ依頼を受け取っていません。
- **進行中**：Agent が作業しているか、Agent が開始したバックグラウンド実行が動いています。
- **対応待ち**：Agent が質問しているか、あなたの承認を待っています。
- **確認待ち**：Agent の作業が止まり、結果があなたの確認を待っています。
- **完了**：あなたが結果を受け取りました。

**進行中** と **対応待ち** は Agent の実際の状態を表すので、カードはこの 2 つの列の間を自動で移動します。カードには実行中の作業とそのステップ数、経過時間が表示され、**停止** を選ぶとその実行を止められます。

## Issue を作成する

1. **Issue を作成** を選びます。
2. タイトルを入力し、何をしてほしいかを書きます。
3. Agent を選びます。パーソナルアシスタントか AI 同僚のどちらかです。
4. **すぐに開始** か **あとで開始** を選び、**Issue を作成** を選びます。

**すぐに開始** を選ぶと、タイトルと説明が Issue の会話の最初のメッセージとして Agent に届き、Agent が作業を始めます。**あとで開始** を選ぶと、Issue は **未着手** のまま待ちます。その間は説明を編集でき、**開始** を選ぶか、カードを **進行中** にドラッグすると作業が始まります。

## 進み具合を確認して結果を受け取る

カードを選ぶと、ボードの横に開きます。**未着手** のカードでは、Issue のタイトルと Agent、依頼の内容が表示され、内容はまだ編集できます。それ以外のカードでは Issue の会話が開き、補足を書いたり、質問に答えたり、実行中の作業に指示を追加したり、作業を止めたりできます。

Agent の作業が止まると、Issue は **確認待ち** に移ります。**完了にする** を選ぶか、カードを **完了** にドラッグすると、結果を受け取ったことになります。**再開** を選ぶと、完了した Issue が **確認待ち** に戻ります。開始する前に完了にした Issue は、依頼の内容を保ったまま **未着手** に戻ります。完了した Issue の会話で Agent が新しいバックグラウンド作業を始めた場合、Issue は自動的に再開されます。

## Issue を見られる人

Issue の会話に参加している人が、その Issue を見られます。同僚と共有したいときは、会話に招待してください。パーソナルアシスタントに任せた Issue は、あなただけが見られます。

会話にいるのがあなただけの間は、あなたが書いたすべてのメッセージに Agent が返信します。同僚が参加すると、会話はグループチャットと同じ扱いになるので、Agent の返信が必要なメッセージでは Agent をメンションしてください。

## Chat から始まったバックグラウンド作業

パーソナルアシスタントとの会話で、アシスタントが最初の Background Agent Job または Workflow を開始すると、その会話は Issue になります。あなたが何もしなくても、その作業はボードに表示されます。AI 同僚との会話など、ほかの会話で Background Agent Job や Workflow が動いている間は、実行が終わるまでその会話もボードの **進行中** に表示されます。

## スケジュールされたタスク

ボードの下の **スケジュール** には、Agent が Chat の一覧にある会話で管理している定期実行と、後で確認する予定が、次回の実行時刻とともに並びます。行を選ぶと、それを管理している会話が開きます。スケジュールを作成または変更するには、その会話で Agent に依頼してください。
