Issue は、Agent に任せるバックグラウンドの作業です。タイトルと説明、そして作業を担当する Agent が 1 つあります。Issue ごとに専用の会話があり、Agent の返信や質問、Agent が開始した Background Agent Job と Workflow が、Chat と同じ形でそこに表示されます。

## Work を開く

Pod のサイドバーで **Work** を選びます。このタブはバックグラウンド作業の受信箱です。タブのバッジは、あなたの回答や確認を待っている Issue の数を示し、一覧ではそうした Issue を先頭に、完了していない Issue が進み具合ごとに並びます。**ボード** を選ぶと Work ページが開き、Issue をボードまたはリストで確認できます。その下にはスケジュールされたタスクが表示されます。Issue にラベルがあるときは、ボードの上でラベルを選ぶと、そのラベルの Issue だけが表示されます。

Work に表示されるのは、Chat の一覧にある会話です。ページのコメントと外部チャットチャネルの会話は Work には表示されないため、そこでの実行やスケジュールはそれぞれの会話で確認してください。

ボードには 5 つの列があります。

- **未着手**：Agent はまだ依頼を受け取っていません。
- **進行中**：Agent が作業しているか、Agent が開始したバックグラウンド実行が動いています。
- **対応待ち**：Agent が質問しているか、あなたの承認を待っています。
- **確認待ち**：Agent の作業が止まり、結果があなたの確認を待っています。
- **完了**：あなたが結果を受け取りました。

**進行中** と **対応待ち** は Agent の実際の状態を表すので、カードはこの 2 つの列の間を自動で移動します。カードには実行中の作業とそのステップ数、経過時間が表示され、**停止** を選ぶとその実行を止められます。

## Issue を作成する

1. **Issue を作成** を選びます。
2. タイトルを入力し、何をしてほしいかを書きます。
3. 必要ならラベルを付けます。複数のラベルはカンマで区切ります。
4. Agent を選びます。パーソナルアシスタントか AI 同僚のどちらかです。
5. **すぐに開始** か **あとで開始** を選び、**Issue を作成** を選びます。

**すぐに開始** を選ぶと、タイトルと説明が Issue の会話の最初のメッセージとして Agent に届き、Agent が作業を始めます。**あとで開始** を選ぶと、Issue は **未着手** のまま待ちます。その間は説明を編集でき、**開始** を選ぶか、カードを **進行中** にドラッグすると作業が始まります。

## Issue をスケジュールで繰り返す

**繰り返し** で **スケジュールで繰り返す** を選び、毎週月曜 9:00 のように実行のタイミングを設定します。実行のたびに Issue の依頼が Agent に届き、結果は Issue の会話に返ってきます。そのため、前回の結果を受け取ったあとでも、実行するたびに Issue は **確認待ち** に戻ります。**すぐに開始** なら最初の実行はすぐに始まり、**あとで開始** なら最初の予定時刻まで待ちます。

カードとパネルには次回の実行時刻が表示されます。パネルか、ボードの下の **スケジュール** から、一時停止、再開、今すぐ実行ができます。Issue の会話で Agent にスケジュールの変更を頼むこともできます。

## サブ Issue に分ける

Issue を開き、パネルで **サブ Issue を作成** を選びます。サブ Issue は独立した Issue で、専用の Agent と会話を持ちます。カードには親 Issue の名前が表示され、親 Issue のカードにはサブ Issue の完了数が表示されます。サブ Issue を完了にすると、親 Issue の Agent が親の会話でその結果をあなたからのメッセージとして受け取り、親の作業を続けます。

## Squad で作業を分担する

Agent にパーソナルアシスタントを選んだときは、**Squad** で AI 同僚を選べます。依頼にはその同僚の名前が入り、アシスタントが同僚と作業を分担します。同僚が担当分を進めている間、Issue は **進行中** のままです。

## 進み具合を確認して結果を受け取る

カードを選ぶと、ボードの横に開きます。**未着手** のカードでは、Issue のタイトルと Agent、依頼の内容が表示され、内容はまだ編集できます。それ以外のカードでは Issue の会話が開き、補足を書いたり、質問に答えたり、実行中の作業に指示を追加したり、作業を止めたりできます。パネルの見出しの下には Issue のラベルが並びます。**ラベルを追加** で付け、ラベルの × で外します。

Agent の作業が止まると、Issue は **確認待ち** に移ります。**完了にする** を選ぶか、カードを **完了** にドラッグすると、結果を受け取ったことになります。**再開** を選ぶと、完了した Issue が **確認待ち** に戻ります。開始する前に完了にした Issue は、依頼の内容を保ったまま **未着手** に戻ります。完了した Issue の会話で Agent が新しいバックグラウンド作業を始めた場合、Issue は自動的に再開されます。

## Issue を見られる人

Issue の会話に参加している人が、その Issue を見られます。同僚と共有したいときは、会話に招待してください。パーソナルアシスタントに任せた Issue は、あなただけが見られます。

会話にいるのがあなただけの間は、あなたが書いたすべてのメッセージに Agent が返信します。同僚が参加したあとも、あなたのメッセージは既定で Issue の Agent 宛てになります。同僚だけに向けて書き、返信するかどうかを Agent に任せたいときは、入力欄の下の宛先を **応答可能な Agent** に変更してください。

## Chat から始まったバックグラウンド作業

Chat の一覧にある会話では、Agent が最初の Background Agent Job または Workflow を開始すると、その会話が Issue になります。パーソナルアシスタントとの会話でも、AI 同僚との 1 対 1 の会話でも、グループでも同じです。あなたが何もしなくてもその作業はボードに表示され、あなたが完了にするまで残ります。同じ会話で新しい Background Agent Job が始まると、Issue は再開されます。

## スケジュールされたタスク

ボードの下の **スケジュール** には、Agent が Chat の一覧にある会話で管理している定期実行と、後で確認する予定が、次回の実行時刻とともに並びます。行を選ぶと、それを管理している会話が開きます。繰り返す Issue のように、あなたの権限で実行される定期実行には、一時停止または再開、今すぐ実行、削除のボタンがあります。それ以外のスケジュールを作成または変更するには、その会話で Agent に依頼してください。
