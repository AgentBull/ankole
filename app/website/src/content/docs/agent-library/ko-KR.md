Agent Library는 PostgreSQL에 Skill 패키지와 Agent 지침을 저장합니다. Pod의 **Meta Ankole → Skills**에서 패키지를, **Agents**에서 AI 동료, 내 어시스턴트, 전체 설정을 관리합니다. Meta 탐색 트리는 기본적으로 접혀 있습니다. 협업 페이지와 Brain 지식 그래프는 각각 별도 영역에서 관리합니다.

## 패키지와 활성화

Skill은 테넌트 내에서 고유한 `slug`, 필수 `SKILL.md`, 선택적인 참조 파일, 스크립트, 바이너리 자산으로 구성됩니다. 사용자 지정 Skill 권한이 있는 멤버는 패키지를 만들거나 가져올 수 있으며, 새 패키지는 기본적으로 비활성화됩니다. Agent는 매니페스트의 안내에 따라 필요한 첨부 파일을 읽습니다. `skill_view`에서는 검토된 Skill lessons도 제공합니다.

모든 Agent, 지정한 AI 동료 또는 내 어시스턴트에 대해 활성화할 수 있습니다. 전체 Agent 활성화를 켜면 개별 스위치를 잠그고 저장된 개별 설정은 보존합니다. 전체 활성화를 끄면 원래 개별 설정으로 돌아갑니다. Plugin에 포함된 Skill은 상위 Agent Plugin도 활성화되어야 합니다. Plugin 자체의 기본값과 재정의 설정은 독립적으로 적용됩니다.

Skill 사용 여부는 Agent 신원에 따라 결정됩니다. 질문자나 참여자가 바뀌어도 활성화된 패키지는 바뀌지 않습니다. Brain 읽기는 Agent, 질문자, 공개 대상자의 권한 교집합을 적용합니다.

## 편집과 업데이트

Skills 편집기에서 매니페스트, 메타데이터, 패키지 파일을 관리합니다. 저장 시 `base_revision`을 비교하여 오래된 버전의 덮어쓰기를 거부합니다. Skill과 지침은 현재 버전만 보관하며 과거 스냅샷은 저장하지 않습니다. 공식 Skill의 `slug`는 고정되며, 사용자 지정 Skill은 이름 변경과 삭제가 가능합니다.

상위 패키지 동기화는 매니페스트와 관리 대상 파일의 해시를 비교합니다. 로컬 수정이 없는 공식 패키지는 파일 추가, 갱신, 삭제를 한 번에 반영합니다. 로컬 수정이 있으면 조정을 마칠 때까지 해당 패키지의 업데이트를 보류합니다. 별도로 업로드한 로컬 첨부 파일은 유지합니다.

## Agent 지침

**Meta Ankole → Agents → 전체 설정**에서 공통 `AGENTS.md`와 `DESIGN.md`를 관리합니다. 각 Agent는 파일별로 상속, 추가, 덮어쓰기를 선택할 수 있습니다. DESIGN 추가 모드는 메타데이터를 재귀적으로 병합하고 본문 사이에 구분선을 넣습니다. 빈 내용으로 덮어쓰면 상속된 내용을 의도적으로 비웁니다.

어시스턴트 설정은 소유자 본인만 읽고 수정할 수 있습니다. 새 어시스턴트는 전용 템플릿으로 AGENTS를 덮어쓰고 DESIGN은 상속합니다. 정식 멤버는 AI 동료와 전체 설정을 볼 수 있으며, 권한이 있는 관리자가 수정합니다.

Worker는 활성 패키지를 `/drive/Skills/<slug>/`에, 병합된 지침을 `/drive/AGENTS.md`와 `/drive/DESIGN.md`에 읽기 전용으로 마운트합니다. 캐시는 대화 간에 공유하며 스크립트의 실행 권한을 유지합니다. 변경 사항을 저장하면 캐시를 갱신합니다. 백그라운드 Job을 재개할 때는 시작 시 기록한 Skill 집합과 현재 활성 집합의 교집합을 사용합니다.
