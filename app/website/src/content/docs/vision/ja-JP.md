ユーザーはチャット上でスクリーンショット、写真、図表などの画像を Agent へ送信できます。通常の Turn で使われるメインモデルが画像入力に対応していない場合、Ankole は自動的に `vision_fallback` プロファイルに設定されたモデルを使って画像を読み取ります。

`primary` に割り当てているモデル自体がすでに画像入力に対応している場合は、`vision_fallback` を空欄のままにして構いません。また、画像を扱う予定がない Agent でも空欄のままで問題ありません。

## 画像 model を設定する

1. **Console → Agents** を開き、対象の Agent を選択します。
2. **Model profiles** 一覧から `vision_fallback` を探します。
3. 画像入力に明示的に対応している Provider とモデルを選択します。
4. プロファイルを保存し、新しい会話を開始します。

なお、管理画面のモデル一覧側で画像入力への対応可否が自動判定されるわけではありません。モデルを選ぶ前に、必ず Provider の公式ドキュメントで画像入力のサポート有無を確認してください。

## 設定を検証する

対象の Agent が接続されているチャットで鮮明な画像を 1 枚送り、画像の中身を見なければ答えられない質問を投げかけてみます。たとえば次のように尋ねます。

> このスクリーンショットにはどのようなエラーが表示されていますか。最も可能性の高い原因を教えてください。

もし Agent が画像を無視したり、「画像を読み取れない」と返答したりする場合は、次の項目を上から順に確認してください。

1. 利用中のチャットチャネルで画像が正常にアップロードされ、Ankole へ転送されているか。
2. 対象の Agent に `vision_fallback` プロファイルが正しく保存されているか。
3. 選択したモデルが実際に画像入力に対応しているか。
4. Provider の認証情報（credential）が有効で、利用クォータに空きがあるか。

なお、画像の読み取りではなく Agent に新しい画像を生成させたい場合は、[Image generation](../image-generation/) を参照してください。画像理解と画像生成では、使用するモデルプロファイルが異なります。
