用户可以在聊天中把截图、照片或图表发给 Agent。如果日常使用的模型不能接收图片，Ankole 会使用 `vision_fallback` 中配置的模型读取图片。

如果 `primary` 本身支持图片输入，可以不配置这项回退。不会接收图片的 Agent 也可以留空。

## 配置图片理解模型

1. 打开 **Console → 智能体**，选择目标 Agent。
2. 在“模型档案”中找到 `vision_fallback`。
3. 选择明确支持图片输入的模型提供商和模型。
4. 保存，然后开始一轮新对话。

模型提供商列表不会替你判断模型是否支持图片。选择前请查看该模型提供商的说明。

## 验证配置

在已经连接该 Agent 的聊天中发送一张清晰的图片，并提出一个只能通过图片回答的问题，例如：

> 这张截图里显示的错误是什么？请告诉我最可能的原因。

若 Agent 只复述文字消息、忽略图片或提示无法读取，请依次检查：

1. 聊天渠道是否成功上传并转发了图片。
2. `vision_fallback` 是否已保存到当前 Agent。
3. 所选模型是否支持图片输入。
4. 模型提供商的凭据和配额是否可用。

需要让 Agent 生成图片时，请阅读 [图片生成](../image-generation/)；图片生成与图片理解使用不同的模型档案。
