用户可以直接在聊天窗口中向 Agent 发送屏幕截图、现场照片或数据图表。如果该 Agent 日常使用的主模型本身不支持视觉输入，Ankole 会自动调用 `vision_fallback` 档案所配置的模型来解析图片内容。

反之，若 `primary` 主模型原生支持图片输入，则无需重复配置此回退项；日常工作完全不涉及图片处理的 Agent 同样可以留空。

## 配置图片理解模型

1. 打开 **Console → 智能体** 页面，点开目标 Agent。
2. 在“模型档案”区域找到 `vision_fallback`。
3. 选择明确支持多模态图片输入的模型提供商与具体模型。
4. 保存配置，并开启一轮新对话使更改生效。

注意，控制台的模型下拉列表不会自动筛除纯文本模型，选定前请先查阅对应模型提供商的文档确认其支持视觉输入。

## 验证配置

前往已接入该 Agent 的聊天窗口发送一张清晰图片，并提出一个必须读懂画面内容才能回答的问题，例如：

> 这张截图里显示的报错信息是什么？请分析最可能的原因。

如果 Agent 仅复述你的文字提问、对图片视而不见或回复无法读取图片，请按以下顺序逐项排查：

1. 当前聊天渠道是否已成功上传图片附件并转发至 Ankole；
2. `vision_fallback` 配置是否已在目标 Agent 名下保存生效；
3. 所选模型本身是否确实具备多模态图片理解能力；
4. 对应模型提供商的访问凭据是否有效、账户配额是否充足。

若希望让 Agent 根据文字描述创作或修改图片，请参阅 [图片生成](../image-generation/)——图片理解与图片生成分别使用各自独立的模型档案。
