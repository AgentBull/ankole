사용자는 채팅방에서 Agent에게 스크린샷, 사진, 차트 이미지를 바로 보낼 수 있습니다. 이때 기본 턴 모델(`primary`)이 이미지 입력을 직접 받지 못하는 모델이라면, Ankole이 자동으로 `vision_fallback` 프로파일에 지정된 모델을 호출해 이미지를 읽어 들입니다.

이미 `primary` 모델 자체가 멀티모달 이미지 입력을 지원하거나, 해당 Agent가 이미지를 다룰 일이 전혀 없다면 `vision_fallback` 프로파일은 비워 두어도 됩니다.

## 이미지 model 구성

1. **Console → Agents**를 열고 대상 Agent를 선택합니다.
2. **Model profiles** 섹션에서 `vision_fallback`을 찾습니다.
3. 이미지 입력을 명시적으로 지원하는 Provider와 모델을 선택합니다.
4. 프로파일을 저장한 뒤 새 대화를 시작합니다.

선택 목록에 나타나는 모델이라고 해서 모두 이미지 입력을 지원하는 것은 아니므로, 지정하기 전에 해당 Provider의 공식 문서에서 멀티모달 지원 여부를 먼저 확인하세요.

## 구성 확인

설정을 마친 뒤 연결된 채팅방에 선명한 이미지를 올리고, 이미지 내용을 읽어야만 답할 수 있는 질문을 보내 보세요.

> 이 스크린샷에는 어떤 오류가 표시되나? 가장 유력한 원인을 알려 줘.

만약 Agent가 첨부된 이미지를 무시하거나 볼 수 없다고 답한다면 다음 항목을 차례대로 점검하세요.

1. 채팅 채널이 이미지를 정상적으로 업로드해 Ankole로 전달했는지 확인합니다.
2. 의도한 대상 Agent에 `vision_fallback` 설정이 정확히 저장되었는지 확인합니다.
3. 선택한 모델이 실제로 이미지 입력을 지원하는 모델인지 다시 확인합니다.
4. 연결된 Provider의 자격 증명과 잔여 할당량(quota)이 유효한지 확인합니다.

반대로 Agent가 새 이미지를 직접 그려 내게 하려면 [이미지 생성](../image-generation/) 문서를 참조하세요. 이미지 이해(`vision_fallback`)와 이미지 생성(`image_generate`)은 서로 다른 모델 프로파일을 사용합니다.
